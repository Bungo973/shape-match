# 三消 × 肉鸽网页小游戏

## 运行

```bash
npm install
npm run dev        # 本地试玩：http://localhost:5173 （加 ?seed=123 固定开局）
npm test           # 规则引擎测试
npm run typecheck  # 引擎与界面的类型检查
npm run assets     # 素材原图缩放为 WebP，输出到 public/game/
npm run sim        # 数值模拟：自动玩家批量打第一段落，见 docs/BALANCE_LOG.md
```

当前可玩：第一段落三战（小怪 → 小怪 → 精英），含开局神器、嵌片三选一与嵌入、营地升级或休息、精英神器奖励与本地续局。左下角是调试工具。

## 已确定的核心规则

任意相邻不同方块都能交换并消耗 AP，不要求匹配；普通未匹配交换保留新排列。玩家也可花 1 AP 点燃一枚无属性炸弹，相邻炸弹交换仍可直接发动组合技。战斗中不提供走法提示。第一次下落前的消除按方块种类产生基数，之后包括炸弹连锁在内的被动消除只提高倍率，最终按 **各类基数 × 倍率** 结算。特殊神器可带明示的负面代价。嵌片是非最终战的基础奖励，同效果一局只获得一块；仅在非战斗阶段可旋转并嵌入，嵌入即固定，商店或特殊事件可取出并送回库存。**神器**开局选一件，后续可从大怪、随机事件和商店获得，持续生效至本局结束。地图按“小怪、小怪、大怪”重复两轮，再以“小怪、小怪、最终 Boss”收尾，商店固定在第 3、6 战后。

## 当前需要讨论的决定

1. 一局目标时长：草案暂按 30–45 分钟、9 场战斗设计，待试玩验证。
2. 催化剂充能：草案让一次主动消除 3 个催化剂获得 1 层充能，下一次发生主动消除的行动给攻击、护盾和毒气基础值各加 3；未消除交换不耗充能。
3. 战后营地、商店与金币的具体数值：当前草案为嵌片升级或休息二选一，普通嵌入不占用选择；非最终战金币暂按敌人类型固定发放，也能从事件中获得，并用于重掷/升级嵌片、购买神器。商店取出嵌片是否收费待定。最终 Boss 胜利后直接结束，不发金币。

这些决定在做原型和数值测试后均可调整；修改时同步更新规则文档和界面说明。
