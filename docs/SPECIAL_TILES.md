# 无属性炸弹与组合（讨论稿）

## 基本身份与计分

棋盘上的基础方块仍只有攻击、护盾、毒气、催化剂四类。横向炸弹 `H`、竖向炸弹 `V`、3×3 炸弹 `A` 和五连炸弹 `CB` 都是**独立、无属性的棋盘方块**，不附着在某种基础方块上，不能参加普通同色匹配。炸弹自身被消耗时不提供任何颜色基数；首次下落后被消耗则计作一个被动清除方块。爆炸清到的四类普通方块仍按来源计数：第一次重力移动前进入各类基数，之后只增加倍率。

炸弹可通过三种方式引爆：玩家花 **1 点行动力点燃一枚炸弹**；两枚相邻炸弹交换组成组合技（也是 1 点行动力）；或被其他爆炸波及。`CB` 与相邻普通方块交换仍可按对方颜色发动，也消耗 1 点行动力。单独点燃、交换组合均属于主动触发，完整处理爆炸队列后才发生第一次重力移动；被动阶段接力引爆仍只增加倍率。单独点燃不移动棋盘位置。

一枚炸弹在一次结算中最多引爆一次，同一方块实体只清除和计数一次。多个范围重叠取并集；炸弹自身不因既被点燃又被别的爆炸扫到而额外计数。

## 生成

| 消除形状 | 生成物 | 单独点燃效果 |
| --- | --- | --- |
| 横向四连 | `H` | 清除所在整行 |
| 纵向四连 | `V` | 清除所在整列 |
| T/L 形相交匹配 | `A` | 清除自身周围 3×3 |
| 直线五连及以上 | `CB` | 随机抽取棋盘现存的一种基础方块类型，清除该类型所有普通方块 |

主动与被动匹配均可产弹。普通产弹会**保留匹配组中的一格并把它替换为无属性炸弹**；该格的原方块不计入这次清除，炸弹也不继承其类型。一次匹配组满足多种条件时只产一枚，优先级仍为 `CB ＞ A ＞ H/V`。随机补位不直接生成炸弹；无嵌片或神器修正时，普通三连不产弹。[土质火药](INSERT_DESIGN.md)是待筛选的三连产弹候选。

主动匹配组产弹位置取属于该组的参与交换方块的交换落点；一次交换形成多个独立匹配组，各组各产一枚。被动匹配组取沿当前重力方向最远的格：向下为最下行，向上为最上行，同一行并列取最左列。产生的炸弹像其他方块一样随之后的重力移动。

### 匹配识别与归组（已确定）

每次检查匹配时，都对当前整盘**同时**执行以下步骤，不按扫描先后逐条处理：

1. **识别匹配线**：找出所有横向、纵向同色普通方块连续 ≥3 格的最长线段。任何炸弹都会打断连续性，例如 `a a H a a` 不构成匹配。
2. **归组**：两条匹配线**共享至少一格**时并为同一组，按传递关系合并。平行相贴而不共享格的线分属不同组；不同颜色的线不可能共享格。
3. **定产物**：组内任一线长 ≥5 → `CB`；否则组内同时含横线和竖线（T、L、十字等）→ `A`；否则组内唯一的线长为 4 → 横线得 `H`、竖线得 `V`；只有三连 → 不产弹。每组至多产一枚。
4. **定产弹格**：主动组取该组的交换落点；被动组取组内沿当前重力方向最远的一行，并列时取最左列。
5. **清除**：各组除产弹格外的格子同时清除；产弹格原方块不计清除，改为对应无属性炸弹。

**主动阶段的不变量**：行动开始前棋盘总是稳定的，没有现成匹配；两枚普通方块交换前后颜色不同；炸弹不参加匹配。因此交换产生的每条新匹配线都必然经过某一个交换落点；每个主动组**恰好包含一个**交换落点，至多由经过该落点的一条横线和一条竖线构成。一次交换最多产生两个主动组。“两枚交换方块同属一组”的情况不会发生，引擎可将其作为断言检查。

坐标记作 `(行, 列)`，第 0 行在最上方。以下实例同时作为自动化测试的期望：

**例 1：一次交换形成两组竖四连。** 交换 `(3,2)↔(3,3)` 前：

```text
      c2 c3
r1     b  a
r2     b  a
r3     a  b   ← 交换
r4     b  a
```

交换后第 2 列 r1–r4 为 `b`，第 3 列 r1–r4 为 `a`，形成两组。`V` 分别产在 `(3,2)` 与 `(3,3)`；每组清除 3 格，共主动清除 3 个 `a` 和 3 个 `b`。

**例 2：主动 T 形含五连。** 落点 `X=(4,2)` 的 `a` 使第 4 行 c0–c4 与第 2 列 r2–r4 同时成线。两线共享 `X`，合为一组；有五连，因此只在 `X` 产一枚 `CB`，其余 6 格主动清除。

**例 3：被动平行横四连。** 下落后第 5、6 行的 c1–c4 均为 `a`，两行不共享格，因此是两组。各产一枚 `H`，分别位于 `(5,1)` 与 `(6,1)`；其余 6 格计入 `P`。

**例 4：被动 L 形。** 下落后第 5 行 c1–c4 与第 4 列 r3–r5 均为 `a`，共享 `(5,4)`，合为一组；没有五连但有横竖交叉，产 `A`。重力向下时取最下行第 5 行、最左列 `(5,1)`；若重力向上，最上行是第 3 行，产弹格为 `(3,4)`。其余 5 格计入 `P`。

**例 5：被动竖四连随重力方向。** 第 6 列 r2–r5 为 `a`：向下重力产 `V` 于 `(5,6)`，向上重力产于 `(2,6)`。

**例 6：一线六连。** 第 7 行 c1–c6 为 `a`，产一枚 `CB`，不再额外产 `H`。

**批量改造的计数口径（已确定）**：若组合技或嵌片把已有的有色普通方块批量改造成炸弹，原方块在改造时按当前主动／被动来源清除并计数一次，新炸弹占据该格。新炸弹若立即引爆，其自身不再作为第二个方块计数；爆炸扫到的其他方块照常计数。这让炸弹本身始终无属性，同时保留原有色方块的结算收益。原本就是炸弹的格不被改造，照常接力引爆。同一波内爆炸清除与改造作用于同一格时，爆炸负责清除计数，改造负责放下炸弹，双方都兑现。

## 普通点燃、移动与接力

- 点燃 `H`、`V` 或 `A`：消耗 1 AP，按上表从炸弹所在格爆炸。点燃 `CB`：消耗 1 AP，随机选一种棋盘现存基础方块类型并全清。随机池为空时只消耗 `CB` 并补位。抽取受本局种子控制。
- `H/V/A` 与相邻普通方块交换而未形成匹配时，只移动并消耗 1 AP，炸弹留在新格，不自动引爆。`CB` 与普通方块交换则发动对应颜色效果。两枚炸弹即使同类型也可相邻交换发动组合技。
- 任意爆炸扫到另一枚炸弹时，后一枚按自身范围接力引爆，沿用原爆炸的主动／被动来源。横向扫到竖向炸弹时，后者清除自己所在列，形成十字。被炸弹波及的 `CB` 与手动点燃一样随机选现存的基础方块类型。`CB` 的同类型清除也算一次爆炸，被清除方块所在格视为被波及，可触发火药等嵌片；爆炸与嵌片的波次结算见[嵌片触发引擎](INSERT_DESIGN.md#触发引擎与消除结算2026-09-27-已确定)。
- 火药嵌片或其他局部效果追加的清除沿用触发事件的来源。清除中的炸弹照常引爆；嵌片效果本身不算一枚新炸弹。

## 相邻两枚炸弹交换

直接交换以组合效果替代两枚炸弹的单独点燃，消耗 1 AP，属于主动清除。第一枚指玩家先选中或拖动的炸弹；其交换后的落点用于下表所说的锚点。范围越界部分略去。

| 组合 | 效果 |
| --- | --- |
| `H+H`、`H+V`、`V+V` | 以第一枚交换落点为中心，清除一行和一列，形成十字 |
| `A+H` | 以交换后 `H` 所在行为中心，清除三行 |
| `A+V` | 以交换后 `V` 所在列为中心，清除三列 |
| `A+A` | 以第一枚交换落点为中心，清除 5×5 |
| `CB+H/V` | 从棋盘现存的基础方块类型中**随机抽一种**；把该类型普通方块全改造为无属性直线炸弹，每枚独立随机横／竖，然后一起引爆 |
| `CB+A` | 随机抽一种现存基础方块类型；把该类型普通方块全改造为无属性 3×3 炸弹，然后一起引爆 |
| `CB+CB` | 覆盖全盘的一次爆炸，清空棋盘；按通用波次规则处理，没有特例 |

`CB` 与相邻**普通方块**交换时，按对方类型清除棋盘上所有该类型普通方块。这是唯一由交换对象直接给出目标类型的 `CB` 组合。`CB+H/V/A` 的对方无属性，因此按用户确定的规则随机选现存基础类型。`CB` 被其他炸弹引爆或由玩家单独点燃，也随机选现存基础类型。随机抽取与批量横／竖方向都由本局种子决定；方向按行、再按列的固定顺序抽取。随机池没有基础方块时，消耗参与的炸弹并进入补位。

范围清除涉及其他炸弹时，它们照常接力；`CB+CB` 清盘后在空棋盘上的接力只是空触发，动画可压缩。普通匹配不能引爆炸弹。组合和普通点燃的实际有色清除进入基数，随后的下落连锁只提高倍率。两枚参与组合的无属性炸弹自身都不提供基数。

## 构筑循环与边界

首版鼓励可重复的构筑链：**三连／四连产弹 → 花 AP 点燃或由易燃物质自动引爆 → 主动清除积累基数 → 重力连锁积累倍率并可能再产弹 → 下一次选择是否继续点燃**。火药与齐射嵌片等嵌片扩大爆炸，覆盖范围升级让循环更容易接上。所有爆炸都要消耗具体炸弹或具体方块实体；同一炸弹不可在一次结算中反复引爆。若自动产弹与自动引爆形成过长连锁，应先用固定种子复盘，再决定合理的单步触发上限，不让战斗卡在无限结算中。

特殊神器可强化产弹、爆炸范围或连锁，也可有明示的负面代价。神器与嵌片追加爆炸都沿用触发阶段，不把被动来源的颜色清除改算基数。
