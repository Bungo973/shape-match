# 视觉风格：构成（现行）

> 2026-09-30 定。转向“三消冲分 + 个人网站作品集”后，美术素材全部停用，画面改为纯代码绘制。四种样板（石墨、瓷釉、矿脉、构成）中用户选定**构成**，以它为基准。样板源码：[prototypes/style-samples.html](prototypes/style-samples.html)（第 4 块棋盘，`STYLES.bauhaus`）。

## 一句话

红、蓝、黄、绿四种平涂几何图形，放在浅色网格上；没有阴影和渐变，动作干脆，带一点回弹。方块只分颜色和形状，没有攻击、护盾、毒气、催化剂等含义。

## 动作

所有时长以毫秒计；系统开启“减少动态效果”时时长乘 0.35，并且不放碎片。

| 动作 | 规格 |
| --- | --- |
| 交换 | 170，easeInOut |
| 不能消除的交换 | 两块互相推进 40%（110，easeOut），再回弹归位（200，backOut） |
| 消除 | 230（有爆炸时 300）：前 25% 放大到 1.2 倍，之后以 backOut 缩到 0，同时旋转约 1.6 弧度 |
| 碎片 | 每块消除迸出 6 片同色平涂碎片（方块、三角交替），向上散开、受重力下落并旋转，700 |
| 直线爆炸 | 黑色粗条从炸弹处向两端扫开，粗细为格宽的 0.34，随时间变细 |
| 范围爆炸 | 黑色圆环从炸弹处扩散、变细 |
| 震屏 | 有爆炸时轻微震动，随爆炸数增强，自然衰减 |
| 下落 | 160×√格数，easeIn：所有方块同一加速度，整列一起落下、不会被拉开；新补的方块在棋盘外叠成一摞整体落入；消除播到 55% 就开始下落；落地后压扁 8%（120） |
| 连爆接力 | 被波及的炸弹 70 后点燃；直线爆炸每格推进 17 |
| 做出炸弹 | 该方块脉冲放大 35%（260） |
| 得分 | 消除中心弹出“+分数 ×倍率”，上升约 0.9 格后淡出，900 |
| 分数栏 | 数字滚动到新值 |

## 声音（第一版，2026-09-30，待试听）

全部用 Web Audio 合成，不用音频文件，代码在 `src/game/audio.ts`。三套音色共用同一组事件，右上角设置浮层（⚙）里可切换比较：**木琴**（默认，基音加高泛音、短衰减）、**玻璃**（调频钟声、余音长）、**方波**（短促电子音），另有静音。音高取 C 大调五声音阶，任意几个音叠在一起都不刺耳。

| 事件 | 声音 |
| --- | --- |
| 选中 / 交换 | 很轻的低音 / 短促的“嗖” |
| 不能消除的交换 | 闷的一下 |
| 消除 | 一个音符；主动消除在最低一级，连锁每深一层往上走一级，清得多时加一个和音 |
| 做出炸弹 | 两音上行 |
| 直线爆炸 / 3×3 爆炸 / 五连爆炸 | 嗖声扫过加轻冲击 / 低频冲击加闷响 / 快速上行琶音 |
| 倍率跨过整数档 | 两音，档位越高越高 |
| 一步结算 | 分数越高，和弦越满（1–4 个音） |
| 新回合 / 神器放炸弹 | 两个轻音 / 两个高音 |
| 过关 / 未达标 | 上行五音 / 下行三音 |

**谢泼德音调（连锁音阶，默认开启，可切回普通）**：连锁消除时，同一音级在 7 个八度上同时发声，音量按频率取钟形分布（中心在 C5 附近）。每深一层升一级，高处分音渐弱、低处分音渐强，听起来一直在往上走，实际音域不变，所以再深的连锁也不会越来越尖。设置浮层里有“▶ 试听”连续播放 8 层连锁。

同类声音 30–80 毫秒内只响一次，大连锁不会糊成一片；总线上有压缩器防止爆音。

## 页面外框（第一版，2026-09-30）

代码在 `src/game/`，入口 `index.html` → `src/game/main.tsx`；旧的 PixiJS 界面（`src/ui/`）不再使用。

| 元素 | 做法 |
| --- | --- |
| 版面 | 五个板块：①顶栏（关卡、生命、金币、⚙）②本关面板（分数与紧贴的进度条、倍率、剩余步数、炸弹等级、首领规则与任务）③棋盘 ④道具栏（棋盘正下方）⑤构筑栏（神器与升级等级）。宽屏（≥1100px）始终三栏：左本关面板 250px（关卡之间换成“本局”栏：总分、九格路线〔黑格已过、黄格下一关、红框首领〕、下一关目标与首领规则、道具背包）、中棋盘或关卡之间的页面、右构筑栏 280px，棋盘按窗口高度放大（360–760px）。窄屏单列：本关面板压成棋盘上方几行（分数与倍率同行），构筑栏收进抽屉，底栏列神器名字 |

## 待定

- 神器目前只有稀有度徽章和名字，还没有图形。稀有度用色：普通黑、罕见蓝、稀有红（卡片上是带字的徽章，神器栏里是小方块）。
- **商店刷新**：“神器”小标题右端一个黑框按钮“刷新 · N”，金币不够时变淡不可点。
- **弱引导**：停手 5 秒后，提示的两格沿交换方向朝对方顶两下（位移 0.1 格，0.65 秒内两次），停 1.15 秒再重复；任何按下或按键立即取消。系统设置“减少动态效果”时不提示。
- **任务**：路线页在规则说明下列出两张任务卡（易为黑徽章、难为红徽章），点选的那张描边变蓝（难为红）并铺浅底，“开始”按所选开关。关内在首领规则下方一行：左侧粗线、徽章、任务说明，右侧等宽字进度（如“5 / 8”“×6.4 / ×8”，速通显示“达标时判定”）；完成时粗线变蓝、整行回弹并闪黄，进度变为蓝色“完成”，响一声。关卡结算卡在分数下写任务结果（完成为蓝色粗体，难任务写出获得的神器），金币明细多一行“任务”。
- **构筑栏**（原神器侧边栏）：宽屏（≥1100px）在棋盘右侧常驻，宽 280px，跟随页面停在顶部。上半是“升级”，下半是神器（神器会越加越多，放下面不挤升级）。升级每行是图标、名字、等级，名字下一行小字写实际数值：方块基数“每块 N 基数”，炸弹“每块 +n−1 基数 · 引爆时倍率 +0.1×(n−1)”。关内显示本关当前等级，引爆够数临时升上去的写成红字“Lv n ↑”。神器每件一张黑框卡片，左边粗线按稀有度着色（普通黑、罕见蓝、稀有红），写名字、稀有度徽章、效果说明，以及红色等宽字的当前状态；空栏合成一行虚线框“还能装 N 件”。商店和领奖时卡片下有“卖出 +N”，点一下变成红底“确认卖出”。窄屏时底栏只列神器名字和“构筑 · 神器 n/6 ▸”，点一下从右侧滑出同样的抽屉（半透明遮罩，点遮罩或“关闭”收起）。
- 关卡结算卡里，香蕉烂掉时用一行红字提示。
- 第一版以可玩为先，细节（音效、过场、移动端手感）待试玩后再定。
