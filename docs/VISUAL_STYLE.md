## 一句话

红、蓝、黄、绿四种平涂几何图形，放在浅色网格上；没有阴影和渐变，动作干脆，带一点回弹。方块只分颜色和形状，没有攻击、护盾、毒气、催化剂等含义。

## 动作

所有时长以毫秒计；系统开启“减少动态效果”时时长乘 0.35，并且不放碎片。

| 动作 | 规格 |
| --- | --- |
| 交换 | 170，easeInOut |
| 不能消除的交换 | 两块互相推进 40%（110，easeOut），再回弹归位（200，backOut） |
| 消除 | 230（有爆炸时 300）：前 25% 放大到 1.2 倍，之后以 backOut 缩到 0，同时旋转约 1.6 弧度 |
| 碎片 | 每块消除迸出 6 片同色平涂碎片（方块、三角交替），向上散开、受重力下落并旋转，700 |
| 直线爆炸 | 黑色粗条从炸弹处向两端扫开，粗细为格宽的 0.34，随时间变细 |
| 范围爆炸 | 黑色圆环从炸弹处扩散、变细 |
| 震屏 | 有爆炸时轻微震动，随爆炸数增强，自然衰减 |
| 下落 | 160×√格数，easeIn：所有方块同一加速度，整列一起落下、不会被拉开；新补的方块在棋盘外叠成一摞整体落入；消除播到 55% 就开始下落；落地后压扁 8%（120） |
| 连爆接力 | 被波及的炸弹 70 后点燃；直线爆炸每格推进 17 |
| 做出炸弹 | 该方块脉冲放大 35%（260） |
| 得分 | 消除中心弹出“+分数 ×倍率”，上升约 0.9 格后淡出，900 |
| 分数栏 | 数字滚动到新值 |

## 声音（第一版，2026-09-30，待试听）

全部用 Web Audio 合成，不用音频文件，代码在 `src/game/audio.ts`。三套音色共用同一组事件，右上角设置浮层（⚙）里可切换比较：**木琴**（默认，基音加高泛音、短衰减）、**玻璃**（调频钟声、余音长）、**方波**（短促电子音），另有静音。音高取 C 大调五声音阶，任意几个音叠在一起都不刺耳。

| 事件 | 声音 |
| --- | --- |
| 选中 / 交换 | 很轻的低音 / 短促的“嗖” |
| 不能消除的交换 | 闷的一下 |
| 消除 | 一个音符；主动消除在最低一级，连锁每深一层往上走一级，清得多时加一个和音 |
| 做出炸弹 | 两音上行 |
| 直线爆炸 / 3×3 爆炸 / 五连爆炸 | 嗖声扫过加轻冲击 / 低频冲击加闷响 / 快速上行琶音 |
| 倍率跨过整数档 | 两音，档位越高越高 |
| 一步结算 | 分数越高，和弦越满（1–4 个音） |
| 新回合 / 印记放炸弹 | 两个轻音 / 两个高音 |
| 过关 / 未达标 | 上行五音 / 下行三音 |

**谢泼德音调（连锁音阶，默认开启，可切回普通）**：连锁消除时，同一音级在 7 个八度上同时发声，音量按频率取钟形分布（中心在 C5 附近）。每深一层升一级，高处分音渐弱、低处分音渐强，听起来一直在往上走，实际音域不变，所以再深的连锁也不会越来越尖。设置浮层里有“▶ 试听”连续播放 8 层连锁。

同类声音 30–80 毫秒内只响一次，大连锁不会糊成一片；总线上有压缩器防止爆音。

## 待定

- 印记目前只有稀有度徽章和名字，还没有图形。稀有度用色：普通黑、罕见蓝、稀有红（卡片上是带字的徽章，印记栏里是小方块）。
- **商店刷新**：“印记”小标题右端一个黑框按钮“刷新 · N”，金币不够时变淡不可点。

- **任务**：路线页在规则说明下列出两张任务卡（易为黑徽章、难为红徽章），点选的那张描边变蓝（难为红）并铺浅底，“开始”按所选开关。关内在首领规则下方一行：左侧粗线、徽章、任务说明，右侧等宽字进度（如“5 / 8”“×6.4 / ×8”，速通显示“达标时判定”）；完成时粗线变蓝、整行回弹并闪黄，进度变为蓝色“完成”，响一声。关卡结算卡在分数下写任务结果（完成为蓝色粗体，难任务写出获得的印记），金币明细多一行“任务”。
