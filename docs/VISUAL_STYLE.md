# 视觉风格：构成（现行）

> 2026-09-30 定。转向“三消冲分 + 个人网站作品集”后，美术素材全部停用，画面改为纯代码绘制。四种样板（石墨、瓷釉、矿脉、构成）中用户选定**构成**，以它为基准。样板源码：[prototypes/style-samples.html](prototypes/style-samples.html)（第 4 块棋盘，`STYLES.bauhaus`）。

## 一句话

红、蓝、黄、绿四种平涂几何图形，放在浅色网格上；没有阴影和渐变，动作干脆，带一点回弹。方块只分颜色和形状，没有攻击、护盾、毒气、催化剂等含义。

| 网格线 | 1px，`rgba(22,22,22,0.10)`，只画内部分隔线 |

| 直线炸弹 | 白色双向箭头，方向与爆炸方向一致；待机时箭头向外轻推（周期约 2.4 秒） |
| 3×3 炸弹 | 白色方框加中心点；待机时方框轻微呼吸 |
| 五连炸弹 | 红、蓝、黄、绿四个圆点缓慢旋转 |
| 待机相位 | 每枚炸弹各自错开，整盘不同步闪动；减少动态效果时静止 |
| 颜色区分 | 颜色与形状一一对应，色弱也能靠形状分辨 |

## 动作

所有时长以毫秒计；系统开启“减少动态效果”时时长乘 0.35，并且不放碎片。

| 动作 | 规格 |
| --- | --- |
| 交换 | 170，easeInOut |
| 不能消除的交换 | 两块互相推进 40%（110，easeOut），再回弹归位（200，backOut） |
| 消除 | 230（有爆炸时 300）：前 25% 放大到 1.2 倍，之后以 backOut 缩到 0，同时旋转约 1.6 弧度 |
| 碎片 | 每块消除迸出 6 片同色平涂碎片（方块、三角交替），向上散开、受重力下落并旋转，700 |
| 直线爆炸 | 黑色粗条从炸弹处向两端扫开，粗细为格宽的 0.34，随时间变细 |
| 范围爆炸 | 黑色圆环从炸弹处扩散、变细 |
| 震屏 | 有爆炸时轻微震动，随爆炸数增强，自然衰减 |
| 下落 | 160×√格数，easeIn：所有方块同一加速度，整列一起落下、不会被拉开；新补的方块在棋盘外叠成一摞整体落入；消除播到 55% 就开始下落；落地后压扁 8%（120） |
| 连爆接力 | 被波及的炸弹 70 后点燃；直线爆炸每格推进 17 |
| 做出炸弹 | 该方块脉冲放大 35%（260） |
| 得分 | 消除中心弹出“+分数 ×倍率”，上升约 0.9 格后淡出，900 |
| 分数栏 | 数字滚动到新值 |

## 声音（第一版，2026-09-30，待试听）

全部用 Web Audio 合成，不用音频文件，代码在 `src/game/audio.ts`。三套音色共用同一组事件，游戏底栏可切换比较：**木琴**（默认，基音加高泛音、短衰减）、**玻璃**（调频钟声、余音长）、**方波**（短促电子音），另有静音。音高取 C 大调五声音阶，任意几个音叠在一起都不刺耳。

| 事件 | 声音 |
| --- | --- |
| 选中 / 交换 | 很轻的低音 / 短促的“嗖” |
| 不能消除的交换 | 闷的一下 |
| 消除 | 一个音符；主动消除在最低一级，连锁每深一层往上走一级，清得多时加一个和音 |
| 做出炸弹 | 两音上行 |
| 直线爆炸 / 3×3 爆炸 / 五连爆炸 | 嗖声扫过加轻冲击 / 低频冲击加闷响 / 快速上行琶音 |
| 倍率跨过整数档 | 两音，档位越高越高 |
| 一步结算 | 分数越高，和弦越满（1–4 个音） |
| 新回合 / 神器放炸弹 | 两个轻音 / 两个高音 |
| 过关 / 未达标 | 上行五音 / 下行三音 |

**谢泼德音调（连锁音阶，默认开启，可切回普通）**：连锁消除时，同一音级在 7 个八度上同时发声，音量按频率取钟形分布（中心在 C5 附近）。每深一层升一级，高处分音渐弱、低处分音渐强，听起来一直在往上走，实际音域不变，所以再深的连锁也不会越来越尖。底栏有“▶ 试听”连续播放 8 层连锁。

同类声音 30–80 毫秒内只响一次，大连锁不会糊成一片；总线上有压缩器防止爆音。

## 页面外框（第一版，2026-09-30）

代码在 `src/game/`，入口 `index.html` → `src/game/main.tsx`；旧的 PixiJS 界面（`src/ui/`）不再使用。

| 元素 | 做法 |
| --- | --- |
| 版面 | 单列，棋盘边长随窗口高度放大（300–760px）；顶栏、分数、进度条、棋盘、步数、底栏自上而下 |
| 线条 | 3px 黑色实线做框与分隔，没有阴影；悬停只做上移与换色 |
| 分数 | Archivo Black 大字，滚动到新值；下方目标进度条为蓝色平涂 |
| 倍率槽 | 5 根竖格，每根一段倍率，连锁中实时填充，有倍率时变红；右侧 ×倍率 与“连锁 n”。不封顶后，5 格填满时数字继续上涨；首领规则“低压”时只剩 2 格 |
| 步数 | 5 组 × 3 个小方格，实心为剩余，当前回合加框；行动力用完自动进入下一回合 |
| 爆破等级 | 三类炸弹图标 + Lv + 黄色细进度条 |
| 得分弹字 | 纸色底块托住黑字，倍率放在下方红色小条里 |
| 结算卡 | 盖在棋盘上，左上角一块原色方块：蓝为达标，红为未达标；下方列出金币收入（过关、首领、剩余步数、合计） |
| 首领规则 | 左侧红色粗竖线 + “首领 · 规则名” + 说明；路线页放大显示，关内显示在分数下方；顶栏关卡号旁黑底“首领”标签 |
| 道具栏 | 棋盘下方一排黑框按钮（图标 + 名字），选中时反白；需要选格的道具，棋盘光标变十字，旁边提示“选一格使用…” |
| 商店 | “升级”“道具”两个小标题分区；卡片底部黄色圆点 + 价格；背包格数写在道具标题旁 |
| 关卡之间 | 黄色眉标 + 大标题 + 黑框卡片（开局神器、精英神器、商店、路线页、终局）；通关页有“继续挑战无尽”，并显示本地最好成绩 |
| 道具与升级图标 | 同一套平涂几何：方块基数为四色田字格，炸弹沿用棋盘上的黑块白标；锤子为黑色锤头加黄色柄，手套为红蓝两块与交换箭头，雷管为黑色起爆器加红色压杆，洗牌为斜放的四色田字格 |
