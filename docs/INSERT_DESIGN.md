# 嵌片设计：简单的格位效果（讨论稿）

## 定位与养成

嵌片的价值来自**覆盖哪些棋盘格**。每块嵌片只有一条容易读懂的局部规则，所有覆盖格同效，没有核心格。初始形状为四格 `I、O、T、L、S`；战后升级只增加一个与自身正交相邻的空格，不提高单格数值，也不改写规则。已安装的嵌片可在非战斗阶段原位扩张，原有格不动；库存中的嵌片也可升级后再旋转嵌入。取出仍只发生在商店或特殊事件，取出后保留扩张形状。

稀有度保留**普通、稀有、高级、完美**，但嵌片均无负面代价。普通提供稳定基数；更高档位逐渐增加产弹数量、爆炸范围或整片引爆的机会。成长来自覆盖范围扩大，高档嵌片还要让玩家看见一次爆发的明显差别。复杂的全局规则与增益仍交给神器。具体嵌片池与掉率待试玩。

战后嵌片奖励采用半引导三选一：独立有用的稳定选择、参考当前构筑的联动选择，以及随机惊喜。候选角色与稀有度分开，具体生成与可放置保护见[地图与营地](MAP.md)。

## 同名重复与扩张价值（重设计方向）

**已确定同名不重复**：一块新的四格同效嵌片会直接扩大覆盖面，使付费升级旧嵌片只增加一格的选择失去吸引力。一局中每种效果最多持有一块；拿到的种类从后续候选中移除，未选择的种类仍可再次出现。扩大某种效果的覆盖面，依靠升级现有嵌片。首版不做同名复制或合并。

现有候选只有八种，而一局有八次非最终战嵌片奖励；若保持三选一，最末次奖励前已经持有七种，池中至少要有十种不同规则才能继续给出三个不同选项。为让重掷仍有变化，首版暂按十二种候选设计。新增规则仍须满足：所有格同效、无核心格、无负面代价、每增加一格都能提高触发机会或爆炸收益。目标是让扩张一块已经摆在关键位置的嵌片，与领取一种新效果成为不同且都值得考虑的成长路径。具体新增种类与稀有度待讨论。

## 火药嵌片（用户提出，重点候选）

> 每当一次爆炸波及这块嵌片，就连带清除嵌片当前覆盖的所有方块。

- 一次爆炸只要触及任意一个覆盖格，就发动一次；同时触及多格不会重复发动。若炸弹本身站在嵌片格上，其爆炸范围包含自身格，因此也会发动。
- 嵌片追加的清除**继承触发爆炸的结算来源**：首次下落前由主动爆炸触发，就按方块类型进入基数；首次下落后由被动爆炸触发，就只增加倍率。这里没有“被动变基数”的例外。
- 被连带清除的其他炸弹照常引爆，继续沿用同一主动／被动来源。每个方块在一次结算中最多清除、计数一次；火药嵌片本身的连带清除不是一枚新炸弹，不会凭空再次触发自己。
- 升级增加一格后，这格既可能让嵌片更容易被爆炸碰到，也会在触发时被一并清除。价值直接来自覆盖范围和摆放位置。

火药嵌片没有负面代价，强度可能适合完美档；稀有度暂不锁定。尤其需要试玩连续爆炸、多个火药嵌片相邻及棋盘边缘时的威力。

## 爆炸方向的候选池

| 候选 | 一句话规则 | 扩张后的爽点 |
| --- | --- | --- |
| 锋刃／壁垒／毒囊 | 主动清除覆盖格，分别增加攻击／护盾／毒气基数。 | 稳定打底，让炸弹爆发有更高基数。 |
| 土质火药 | 原本不产弹的普通三连若清到覆盖格，该组也留下一枚无属性的对应方向直线炸弹。 | 更容易接住三连，棋盘逐渐堆出可手动点燃的炸弹。 |
| 易燃物质 | 无属性炸弹在覆盖格生成时立即引爆，不额外花费行动力。 | 扩张后更容易接住产弹落点，当步就能连爆。 |
| 齐射嵌片 | 直线炸弹扫到覆盖格时，嵌片内**未被该炸弹扫到**的方块变成同方向无属性直线炸弹并立即引爆。 | 横炸弹可扩成多行齐射，竖炸弹可扩成多列齐射。 |
| 火药嵌片 | 任意爆炸扫到覆盖格，就连带清除整块嵌片。 | 扩张让它更易被点燃，也让一次触发清得更多。 |
| 爆裂晶体 | 任意爆炸扫到覆盖格，整块嵌片上现存方块变成无属性 3×3 炸弹并同时引爆。 | 扩张一格等于潜在多一枚 3×3，适合完美档大爆发。 |

这些只是方向候选，全部没有扣血、失效或其他负面效果。土质火药只改变普通三连，四连及以上仍按现有炸弹优先级；产弹格按既有主动／被动落点选择，保留格不计清除。齐射嵌片与爆裂晶体把有色方块变为无属性炸弹时，暂按原方块在改造瞬间依触发来源清除并计数一次、新炸弹自身不再重复计数处理，详见[无属性炸弹规则](SPECIAL_TILES.md)。

### 补足唯一制奖励池的四个新候选

现有八种效果加上以下四个候选，可形成十二种不同规则。名称、稀有度和是否进入首版仍待筛选；以下规则都只依赖覆盖格，不设置核心格。

| 候选 | 局部规则 | 扩张一格的直接价值 |
| --- | --- | --- |
| 催化盐（普通候选） | 主动清除覆盖格内的催化剂时，额外计入一枚催化剂的主动清除数。 | 多一个能够帮助储能的格位。 |
| 火星陶（稀有候选） | 覆盖格上的横／竖炸弹被单独或接力引爆时，额外从该格引发一次 3×3 爆炸。 | 多一个能把直线爆炸扩成范围爆炸的格位。 |
| 震裂石（高级候选） | 覆盖格上的 3×3 炸弹被单独或接力引爆时，将本枚炸弹的范围改为 5×5。 | 多一个可放大 3×3 炸弹的格位。 |
| 星火矿脉（完美候选） | 无属性炸弹在覆盖格生成时，其他覆盖格中尚存的普通方块各变成随机方向的直线炸弹并立即引爆。 | 可能多转化并引爆一枚炸弹，同时增加触发落点。 |

火星陶与震裂石只修改站在覆盖格上引爆的炸弹，不改动远处经过嵌片的炸弹；炸弹组合技以其组合范围结算，不叠加两种单弹改造。星火矿脉生成的额外炸弹沿用当前主动或被动来源，不能把被动清除转成基数。四项仍是待讨论提案，先用它们检验“规则唯一、扩张有用、爆炸够爽”的筛选标准。

**可能的构筑循环**：土质火药让普通三连产出无属性炸弹；玩家花 1 点行动力点燃已有炸弹，或由易燃物质自动点燃新弹；爆炸扫过火药嵌片和齐射嵌片，清掉大量有色方块，第一次下落前形成各类基数；下落连锁提高倍率，还可能在扩张后的嵌片上产出下一批炸弹。每次新炸弹与新方块都是循环的实际投入，结算完成后玩家再决定是否花行动力点燃下一枚。

## 与神器的边界

原来的折光导轨需要规定炸弹在嵌片内引爆时如何折射、折射线能否再次触发等，持续改变炸弹路径，更适合放在神器灵感池。爆炸预热的“四次充能 → 全格变 3×3 炸弹 → 被动释放也算基数”属于更复杂的状态与计分例外，暂从嵌片池移出。这里的爆炸候选都只作用于覆盖格或从覆盖格直接发出清除，清除仍按触发时的主动／被动来源计分。

## 首版嵌片池（2026-09-27 名单已定）

首版收录以下十二种，档位如表；名称与数值仍可在试玩后调整。上文“爆炸方向的候选池”保留作设计来由，**实现以本节为准**。所有嵌片的触发都服从下节的触发引擎；“主动／被动”指触发发生在第一次重力移动之前或之后，追加的清除与改造一律沿用触发来源。改造有色方块为炸弹时，按[批量改造计数口径](SPECIAL_TILES.md#生成)计数一次。

| 档位 | 嵌片 | 精确规则 |
| --- | --- | --- |
| 普通 | 锋刃／壁垒／毒囊 | 主动阶段，每有一个**同色**普通方块（攻击／护盾／毒气）在覆盖格上被清除，无论由匹配还是爆炸清除，对应的 `E攻击／E护盾／E毒气` 加一份每格数值（原型暂定 2）。异色方块、炸弹和被动阶段的清除都不触发。 |
| 普通 | 催化盐 | 主动阶段，覆盖格上每清除一个催化剂，额外计入一个主动催化剂清除，参与 `A催化剂`、结算分和充能累计。 |
| 稀有 | 土质火药 | 一个只含一条三连线、原本不产弹的匹配组，只要任一格在覆盖格上，就产一枚与该线同向的直线炸弹（横线 `H`、竖线 `V`）。产弹格按通用规则：主动取交换落点，被动取重力方向最远、最左格；产弹格不必在覆盖格内。主动与被动匹配都适用。 |
| 稀有 | 易燃物质 | 任一炸弹在覆盖格上**生成**时（匹配产弹、土质火药产弹或被改造而成），在下一波引爆，不耗行动力。炸弹因交换或重力**移动**到覆盖格不算生成。本来就会立即引爆的改造炸弹不重复引爆。 |
| 稀有 | 火星陶 | 站在覆盖格上的 `H／V` 被单独点燃、接力引爆或作为改造出的炸弹引爆时，同一波内额外以该格为中心发生一次 3×3 爆炸。两枚炸弹直接交换的组合技按组合范围结算，不追加。 |
| 高级 | 火药嵌片 | 一次爆炸波及任一覆盖格时，清除所有覆盖格上的方块；其中的炸弹在下一波引爆。追加清除不是新爆炸。 |
| 高级 | 齐射嵌片 | 单枚直线炸弹的爆炸（含接力，以及 `CB+H/V` 改造出的直线炸弹）扫到任一覆盖格时，覆盖格内**未被该爆炸扫到**的普通方块变成同方向的直线炸弹，在下一波引爆。十字、三行、三列等组合技范围是否触发暂不启用，待原型复盘。 |
| 高级 | 震裂石 | 站在覆盖格上的 `A` 被单独点燃、接力引爆或作为改造出的炸弹引爆时，其范围由 3×3 改为 5×5。组合技按组合范围结算，不叠加。 |
| 完美 | 爆裂晶体 | 一次爆炸波及任一覆盖格时，覆盖格上现存的普通方块变成 `A`，在下一波引爆。与同一波爆炸作用于同一格时，按“改造 = 清除 + 放炸弹”处理，见下节。 |
| 完美 | 星火矿脉 | 任一炸弹在覆盖格上生成时，其他覆盖格上现存的普通方块各变成随机方向的直线炸弹（方向由本局种子按行、再按列抽取），在下一波引爆。在生成触发步骤结算，只改造本波清除与改造之后仍存在的普通方块，见下节。 |

四种普通嵌片都只认同色或同类方块，因此它们的价值同时取决于摆放位置和该颜色的生成权重。

## 触发引擎与消除结算（2026-09-27 已确定）

以下规则与具体嵌片种类无关，所有炸弹、嵌片和神器效果都按此框架结算。

### 阶段与波次

一次行动由**主动阶段**（第一次重力移动之前）和若干**被动阶段**组成，阶段之间是一次重力移动与补位。每个阶段按以下顺序结算：

1. **发起**：主动阶段为交换形成的匹配、单独点燃、炸弹组合技或 `CB` 与普通方块交换；被动阶段为重力移动与补位后整盘找匹配。
2. **匹配结算**：按[匹配识别与归组](SPECIAL_TILES.md#匹配识别与归组已确定)清除与产弹，土质火药在此生效。普通匹配**不是爆炸，也不能引爆炸弹**；炸弹只能由点燃、组合技、爆炸波及或嵌片效果引爆。
3. **波次循环**，本波有待引爆的炸弹时依次执行：
   - a. **定范围**：计算本波每个爆炸的范围；震裂石、过载引线、火星陶等范围修正在此生效。`CB` 在此抽取目标类型，多枚 `CB` 按行、再按列的顺序，从本波开始时的棋盘抽取。
   - b. **清除**：本波所有爆炸范围的并集，加上火药等嵌片的追加清除。范围内的有色方块清除并计数一次；范围内的炸弹记为下一波引爆。
   - c. **改造**：组合技、爆裂晶体、齐射等把目标格改为炸弹。改造对象按**本波开始时的快照**判定，只针对有色普通方块；原本就是炸弹的格不被改造，照常接力。改造 = 清除原方块（若 b 步尚未清除，此时计数一次）+ 在该格放下炸弹，新炸弹在下一波引爆。
   - d. **生成触发**：本波放下的炸弹或第 2 步产出的炸弹若落在易燃物质、星火矿脉等覆盖格上，在此触发；其改造按 c 步之后的棋盘判定。
   - e. **记录**：写入结算日志。
4. 本波没有新的待引爆炸弹时，本阶段结束，执行重力移动进入下一被动阶段；重力移动后没有匹配、也没有待引爆炸弹时，行动结束。

同一波内，清除取并集，改造在清除之后，生成触发在改造之后，因此**结果与同波内部的处理先后无关**。每个方块实体在整次行动中只清除、计数一次；每枚炸弹只引爆一次。同一块嵌片每波至多判定一次，不同波之间不设上限。

### 爆炸的定义与特殊情况

- **爆炸**包括 `H/V/A` 的单独引爆与接力、所有炸弹组合技的几何范围、被改造出的炸弹的引爆，以及 `CB` 的同类型清除（只有被清除方块所在格视为被波及）。普通匹配清除不是爆炸；火药等嵌片的追加清除也不是新爆炸。
- **`CB+CB` 没有特例**：视为覆盖全盘的一次爆炸，按通用规则处理。满足条件的嵌片在清屏的那一波触发；随后在空棋盘上发生的爆炸只是空触发，动画可压缩为一闪。清屏后立即下落补位，被动连锁照常进行。
- **空触发不算触发**：嵌片被触及时，若覆盖格上已没有可作用的对象，不产生清除、改造、基数或范围变化，就不算触发，不写入日志、不播放反馈，也不计入任何按触发次数判断的神器条件。

### 结算与呈现的分工

结算只按上面的阶段与波次计算，结算日志是动画的唯一数据源。动画可让每个爆炸从锚点按距离逐格向外扩散，扩散到嵌片时嵌片亮起，扩散到炸弹时该炸弹开始自己的扩散；每个阶段结束后方块快速下落。第 k+1 波的炸弹必定被第 k 波的某个爆炸触及，因此这种呈现与结算的因果一致。动画不得改变结算结果。

### 防卡壳的五条设计规矩（硬性审查标准）

所有嵌片、神器与敌人效果进入正式池前必须满足以下五条；不满足的设计退回重写，不以特例补丁放行。

1. **消耗原则**：会引发新触发的效果，必须消耗具体的方块或炸弹；同一阶段内不得凭空增加方块。以“有色方块数 ×2 + 未引爆炸弹数”为总量，每次有效触发都严格减少，因此每个阶段必定终止。
2. **不跨阶段存状态**：不设“已触发、待执行”或“下次补位后生效”的挂起效果。
3. **只作用于自身**：嵌片的直接效果只作用于自身覆盖格，或只修改站在自身覆盖格上的炸弹。嵌片之间不重叠，因此同一波内不会争夺同一格。
4. **只用三种动作**：清除（取并集）、改造（在清除之后）、修改范围（在清除之前）。需要依赖“先 A 后 B”才能成立的设计不进池。
5. **五问齐全**：每条规则写明谁触发、何时、作用于谁、主动还是被动来源、目标为空时怎样。

跨重力步的长连锁只由随机补位推进，逻辑上不截断。工程保护：超过若干阶段后动画自动快进，日志标出异常长的连锁供复盘；设置的硬上限只作为程序错误保护，不是设计规则。

### 分批实现

十二种嵌片的规则全部写定，但按边缘成本分批实现：

| 批次 | 嵌片 | 性质 |
| --- | --- | --- |
| 第一批（三战原型） | 锋刃、壁垒、毒囊、催化盐、土质火药、火星陶、震裂石、火药嵌片、易燃物质 | 修饰型七种，加追加清除的火药与唯一的自动点火件 |
| 第二批 | 齐射嵌片、爆裂晶体、星火矿脉 | 生成并引爆新炸弹，待原型验证连锁可读后加入 |

第一批只有九种，够三战原型使用；完整九战版需要第二批到齐，才能维持后期的三选一。若原型显示生成爆炸型连锁难以理解，备选方案是：除易燃物质外，嵌片生成的炸弹只留在棋盘上，等待玩家花行动力点燃。

## 仍需确定

1. 各档掉率；高级也不附带负面效果，完美以更大的清屏潜力区分。
2. 单块最大覆盖格数及扩张费用留待试玩调整。
3. 主动阶段的基数没有上限：一次点燃可能经火药、爆裂晶体等多波连锁全部计入主动基数。原型需统计单步主动基数的分布，必要时对嵌片追加清除或单步基数设上限。
