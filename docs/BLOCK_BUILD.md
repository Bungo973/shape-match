# 方块构筑（讨论稿）

> 状态：**2026-09-29 讨论稿，部分已定（见“已确定”），未实现。**来由见 [DESIGN_JOURNAL](DESIGN_JOURNAL.md) 2026-09-28 第 3–4 节：嵌片在战斗中不参与选择，显得多余，决定去掉嵌片，成长改为“方块构筑”，即强化方块与炸弹，并加入极少量（2–3 种）特殊方块，**不调整四色方块的生成比例**。现行规则仍以 [GAME_RULES](GAME_RULES.md) 为准。

## 一句话

玩家不再往棋盘上摆东西，而是**升级方块本身**：4 种基础方块与现有 3 类炸弹各有等级，规则统一为“等级 × 基础值”。更复杂的变化交给神器，战斗中的主动选择交给传统道具。**保持简单**是这一版的首要约束（2026-09-29 用户确定）。

## 先确认的结构性事实

以下几条直接决定了设计框架，不需要再讨论：

1. **玩家无法“拥有”某一格方块。**棋盘上的方块不断被清除、补入，任何挂在单格上的强化都会在几步之内消失。因此强化只能挂在**方块类型**（所有攻击方块）或**生成规则**（补位时出现什么）上。类型级强化不在棋盘上存任何状态，天然满足防卡壳规矩第 2 条（不跨阶段存状态）和第 3 条（只作用于自身），也不需要棋盘编辑器、摆放和取出服务。
2. **去掉嵌片后，被动阶段没有任何爆炸来源。**普通匹配不能引爆炸弹；被动阶段的爆炸原本只由“易燃物质”点燃（`src/engine/resolve.ts` 中唯一的被动波次入口），火药、齐射等嵌片再在波次内扩散。嵌片一去，被动阶段只剩匹配与下落。
3. **倍率这一项现在是纯运气。**模拟器中熟练玩家的平均倍率为 2.59，新手为 2.43，几乎相同；单步伤害的波动 61% 来自基数、28% 来自倍率（2026-09-28 统计，见 [BALANCE_LOG](BALANCE_LOG.md)）。结合第 2 条：**方块构筑若不补上倍率这一侧的成长，玩家只能养基数。**
4. **特殊方块可以附着在普通方块上，不另占生成名额。**补位时先按原权重抽颜色，再按构筑决定这一格是否带特性；四色比例因此不变。

## 已确定（2026-09-29）

1. **升级项只有两类，共 7 项**：4 种基础方块（攻击、护盾、毒气、催化剂）和现有 3 类炸弹（直线 `H/V`、范围 `A`、五连 `CB`）。不引入牌型表，不新增炸弹类型。
2. **统一规则：等级 × 基础值**，初始都是 1 级。

| 升级项 | 1 级 | 每升一级 | 结算时机 |
| --- | --- | --- | --- |
| 攻击／护盾／毒气方块 | 主动清除时每块计 1 | 每块 +1 | GAME_RULES §2 第 2 步，计入 `A` |
| 催化剂方块 | 主动清除时每块计 1（参与 `A催化剂`、结算分与充能累计） | 每块 +1 | 同上 |
| 直线炸弹 | 亲手做出时，该匹配组颜色基数 +3 | +3 | 主动产弹时 |
| 3×3 炸弹 | 亲手做出时，该匹配组颜色基数 +4 | +4 | 主动产弹时 |
| 五连炸弹 | 亲手做出时，该匹配组颜色基数 +6 | +6 | 主动产弹时 |

3. **主动爆炸清除的方块照常按颜色计入基数**（GAME_RULES §2 第 2 步不变），并享受方块等级：例如攻击 2 级时，主动炸弹炸掉的每个攻击方块计 2。
4. **炸弹升级的额外加成在“亲手做出”时给**：炸弹本身无属性，爆炸那一刻没有可归属的颜色，做出炸弹的匹配组则有。被动产弹没有这笔加成（被动阶段只影响倍率）。
5. **取代“亲手特殊匹配 ×2”**（`activeSpecialMatchFactor`）。量级接近：四连现为 4 块 ×2 = 8，新规则为 4 + 3 = 7。
6. **成长只喂基数**。倍率一侧先靠更大的棋盘与神器（见下），导火索、晶核等方块层面的倍率设计暂缓。
7. **棋盘 10×10**（见 [BOARD_SIZE_DECISION](BOARD_SIZE_DECISION.md)）。

## 十字炸弹（2026-09-29 撤回）

曾提出由田字（2×2 同色）匹配产出、清除上下左右相邻格的十字炸弹。考虑到它要扩展炸弹组合规则、还需新素材，决定不做，保持现有 3 类炸弹。

## 神器：条件基数与炸弹变化

复杂的变化放在神器，升级表保持简单。以下候选只修改计数或范围，不产生新触发，天然满足防卡壳五条规矩：

| 候选 | 规则 |
| --- | --- |
| 纯色 | 本步主动只清除了一种颜色，该色基数 +3 |
| 彩虹 | 本步主动清除了四种颜色，每类基数 +2 |
| 炸弹匠 | 本步亲手做出炸弹，每枚再给该组颜色基数 +2 |
| 大清除 | 本步主动清除 ≥10 格，每类基数 +1 |
| **闪电引线**（用户提出） | 直线炸弹爆炸（单独点燃、接力或由五连改造）时，在直线两侧 2 行／列内、直线未扫到的格中，按种子分散地随机清除 5–8 格；来源沿用该炸弹；被击中的炸弹在下一波引爆；不足时有几格清几格。组合技首版不触发。 |

## 道具：传统三消道具（方向已定，细则待定）

不做卡牌（卡牌原型已否决），也不做带修饰效果的药剂，改用玩家熟悉的传统道具，例如锤子（砸掉一格）、放一枚炸弹、任意两格互换。待定：栏位数、是否耗行动力、每回合使用次数、来源（商店、事件、精英）、道具清除算主动还是另计。

## 奖励与营地

- **战后三选一**：候选从 7 个升级项中抽取，沿用稳定／构筑／惊喜三个位置（`src/engine/rewards.ts`）。同名重复出现即再升一级。
- **营地**：升级与休息二选一保留；升级改为“任选一项 +1 级”。奖励决定方向，营地决定加码。
- **金币**：继续用于重掷、营地升级、商店神器；“取出嵌片”服务取消。
