# Boss 重力异常（首版上下反转）

## 已确定

- 默认重力向下。首版 Boss 重力异常将其**反转为向上**；左、右方向仅作为后续扩展预留，首版不会施加。改变重力是 **Boss 施加的负面状态**，不作为玩家神器或其他增益能力。
- 玩家交换形成多个独立产弹匹配组时，每组各生成一枚，先出现在属于该组的参与交换方块的落点；主动清除和炸弹接力完成后，炸弹才与普通方块一起沿当前重力方向移动。嵌片固定在棋盘格上。
- 被动匹配生成的炸弹保留在该匹配组沿当前重力方向最远的一格：正常向下取最下行，异常向上取最上行；并列时取最左列。产弹格不计入被动清除数。
- 第一次重力移动是主动／被动计分边界。即使方向反转为向上，重力造成的匹配、产弹和爆炸都只增加倍率。
- Boss 的重力意图和目标方向在玩家行动前公开；若毒气眩晕取消该意图，本次重力异常不施加。
- **反转状态生效期间，Boss 不再选择重力反转意图**，也不会刷新或叠加剩余回合数；状态结束后，该意图才重新进入候选。

现有规则文档中的“下落”是重力移动的简称，不要求移动方向始终向下。

## 结算模型建议

Boss 行动成功后，重力异常从**下一个玩家回合**开始，暂定持续 **3 个完整玩家回合**。每个受影响回合内的所有交换都使用向上重力；玩家主动提前结束回合也计作一个回合。该玩家回合结束、所有交换结算完成后，剩余回合数减 1；第三个受影响回合结束后恢复向下。向上时，现有方块向棋盘上边填补空格，新方块从**下边缘**补入；正常向下时从上边缘补入。一次交换从第一次重力移动到棋盘稳定，方向保持不变。单纯改变方向不会移动满盘方块。规则引擎可预留四方向参数，但首版只需要向下和向上两种值。

战斗页显示当前重力方向、Boss 预告的目标方向及剩余持续时间。结算日志记录每次交换采用的方向；横向、竖向炸弹仍按棋盘的行与列定义，不随重力方向旋转。
