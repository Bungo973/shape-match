# 嵌片卡玩法（讨论稿）

> 状态：**讨论中，尚未实现**。本文记录“以嵌片卡取代交换”的新方向。定稿并经原型验证前，现行规则仍以 [GAME_RULES](GAME_RULES.md) 等文档为准；定稿后再统一改写旧文档。

## 一句话

棋盘仍是三消棋盘；玩家不再交换方块，而是**打出嵌片卡**——一块俄罗斯方块形状的“炸弹”——清除它覆盖的格子，再由重力下落引出连锁。

## 为什么转向

- **嵌片成长有了直接动力**：卡的形状就是清除范围，升级加一格立刻变强；旧版“嵌入棋盘、升级只加一格”的价值不直观。
- **每一步都是明确的决策**：放在哪、朝哪个方向，而不是在满盘中寻找可交换的位置。
- **构筑框架成熟**：抽牌、费用、加卡、升级卡的卡牌构筑结构可以直接承接肉鸽成长。
- **三消的爽点保留**：下落连锁、倍率、炸弹生成照旧，只是从“亲手凑三连”变成“挖掉一块，看它怎么落”。

## 已确定（2026-09-28）

1. **棋盘与连锁不变**：四种基础方块、重力下落与补位、被动匹配、倍率、炸弹的生成与爆炸规则沿用现行规则。
2. **主动操作只有打出嵌片卡**：取消交换。卡片清除被覆盖的格子，这些清除是**主动清除**，按颜色计入基数；之后的下落连锁照旧只提高倍率。
3. **嵌片就是炸弹**：打出卡片与一次爆炸用同一套结算逻辑。被覆盖的普通方块被清除；被覆盖的炸弹被引爆，并照常接力。
4. **炸弹只能被动生成**：只有下落连锁里形成的四连、五连、T/L 形会产出炸弹。
5. **嵌片转为卡**：锋刃、壁垒、毒囊、催化盐四种基础嵌片直接转为卡；其余不好转化的嵌片先移出。
6. **神器随之调整**：依赖“已安装嵌片”的神器视情况改写或移除。
7. **放置规则**：卡片必须整块位于棋盘内；可以覆盖炸弹；放下前可自由旋转，支持**鼠标滚轮旋转**（另保留 R 键与右键）。放置时显示将覆盖哪些格——这属于输入确认，不违反“不预览结果”；不显示后续连锁。
8. **奖励改为卡牌**：战后的嵌片三选一改为卡片三选一，加入牌组。**允许重复**的卡片。营地升级改为给一张卡增加一格。

## 卡牌分类（2026-09-28 确定）

卡牌分三类，此后的卡牌都朝这三类设计：

| 类别 | 作用 | 说明 |
| --- | --- | --- |
| **消除卡** | 以形状清除棋盘格子 | 基础卡只清除；属性卡在清除基础上带颜色词条（锋刃、壁垒、毒囊、催化盐：覆盖对应颜色时额外加基数）。升级增加一格 |
| **状态卡** | 对棋盘或本回合施加增益 | 两种形式：到回合结束为止的**全局增益**（如本回合某类基数提高、倍率提高一档、炸弹范围扩大），与持续若干回合的**棋盘区域标记**（在某块区域清除时获得增幅） |
| **功能卡** | 维持牌组运转 | 抽牌、回费、保留手牌等。升级为增强效果或降低费用，每张卡设计时写明 |

原先设想的“炸弹卡”“连锁卡”不单独成类，其效果以状态卡的形式出现。基础卡暂不设为 0 费。

另有两类非奖励卡：

- **关键词**：首版引入少量关键词，例如“消耗”（本场战斗只能使用一次）、“保留”（回合结束不弃掉）。具体清单待定。
- **干扰卡**：敌人塞入牌组的无效或有害卡（例如“碎石”），不进奖励池，用来替代“嵌片压制”。具体设计待定。

**防循环约束**：任何卡返还的费用不得大于等于自身费用；抽牌类功能卡至少 1 费或带“消耗”，避免“打出 → 抽到 → 再打出”的循环（对应防卡壳规矩第 1 条）。

## 回合与手牌（2026-09-28 部分确定）

- 每回合 **3 点费用**，不跨回合保留。
- **回合结束时手牌全部放入弃牌堆**（带“保留”的卡除外）。
- 抽牌堆耗尽时，把弃牌堆洗回成新的抽牌堆；洗牌顺序由本局种子决定。
- **每回合抽 5 张**，**手牌上限 10 张**（超出的抽牌跳过），**起始牌组 5 张**。

**起始牌组（方案 C）**：4 张基础卡 + 1 张属性卡；属性卡在开局时从锋刃、壁垒、毒囊、催化盐中选一张，与开局神器一起构成两个开局选择。4 张基础卡用哪几种形状待定。**费用逐张设计**，不设统一规则。

**由此带来的设计点**

- **前期手牌固定**：牌组只有 5 张时每回合全部抽到，没有抽牌运气，决策集中在摆放上，适合上手。
- **加卡是真正的取舍**：牌组超过 5 张后每回合有卡抽不到，弱卡会稀释强卡。因此战后奖励应**允许跳过**（可补偿少量金币），并需要**删卡服务**（例如商店）。
- **抽牌是重要的构筑方向**：设计抽牌相关神器（多抽、提高手牌上限、保留手牌等）。抽牌类功能卡在牌组较大时才有价值，自然成为中后期选择。

## 旧系统的去留

| 旧系统 | 去留 |
| --- | --- |
| 交换（含未消除交换铺路） | 取消 |
| 点燃炸弹（花 1 AP） | 取消，由卡片覆盖炸弹来引爆 |
| 两枚炸弹交换的组合技、`CB` 与普通方块交换 | 取消；是否以“卡片同时覆盖两枚相邻炸弹”来保留组合技，**待定** |
| 主动匹配产弹、主动组的交换落点规则 | 取消（不再有主动匹配） |
| 被动匹配归组与产弹落点 | 保留 |
| 波次结算、爆炸定义、防卡壳五条规矩 | 保留，卡片视为一次主动爆炸 |
| 嵌片嵌入棋盘、嵌入即固定、最多安装 6 块、取出服务、棋盘编辑器 | 取消 |
| 同名嵌片不重复 | 取消，卡片可重复 |
| 嵌片三选一的稳定／构筑／惊喜生成器 | 改造为卡片奖励生成 |
| 营地升级／休息 | 保留，升级对象改为卡片 |
| 敌人：嵌片压制 | 改为针对手牌或牌组（如封印一张卡），**待定** |
| 敌人：倍率侵蚀、重力反转 | 保留；重力反转在新玩法中影响更大 |
| 计分（主动基数 × 被动倍率）、护盾、毒气、催化剂 | 保留 |

### 神器初步去留

| 神器 | 初步判断 |
| --- | --- |
| 共振底座（同一步触发两块嵌片） | 前提消失，移除或改写 |
| 锁位共鸣器（相邻嵌片联动） | 前提消失，移除 |
| 精工刻刀（升级多加一格） | 保留，作用于卡片升级 |
| 拾荒眼镜、藏宝图残页 | 保留，作用于卡片奖励 |
| 过载引线、不稳定引信 | 保留（炸弹仍存在；“主动引爆”改指被卡片覆盖引爆） |
| 其余（穿甲针、密封毒瓶、反应线圈、连锁透镜、回响钟） | 不受影响 |

## 待讨论

1. **卡牌分类**：已确定为消除／状态／功能三类，见上节；补充待定项仍需确认。
2. **手牌经济**：已定（费用 3、抽 5、上限 10、起始 5 张、回合末弃牌）。跳过奖励的补偿与删卡服务的价格待定。
3. **费用**：已定为逐张设计。
4. **起始牌组**：已定方案 C；4 张基础卡的形状组合待定。
5. **卡片成长的边界**：单张卡的最大格数；升级除了加格是否还能改变效果；是否需要删卡服务（例如商店）。
6. **炸弹组合技**：是否以“卡片同时覆盖两枚相邻炸弹”保留十字、三行、5×5 等组合。
7. **卡片来源的控制**：卡片是否只来自战后奖励；商店是否卖卡；事件如何给卡。
8. **敌人对卡牌的干扰**：“嵌片压制”改成什么；是否增加塞废卡、加费用等卡牌游戏常见的干扰。
9. **催化剂的角色**：在卡牌框架里是否可以转为“下回合多抽牌或多费用”等更贴切的效果。
10. **移出的嵌片效果**：土质火药、易燃物质、火药嵌片等是否以神器或高稀有卡的形式回归。
