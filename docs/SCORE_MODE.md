# 冲分模式：现行规则（2026-10-06）

> 这是冲分模式**当前实际生效**的规则汇总，数值以 `src/engine/config.ts` 为准。每条规则为什么这样定，见 [DESIGN_JOURNAL](DESIGN_JOURNAL.md) 第 9–17 节；数值来由见 [BALANCE_LOG](BALANCE_LOG.md)；画面与声音见 [VISUAL_STYLE](VISUAL_STYLE.md)。打怪模式（敌人、护盾、毒气）已搁置，[GAME_RULES](GAME_RULES.md) 中与之相关的部分不适用。

## 一局的流程

开局从 3 件普通神器里选 1 件 → 第 1 关 → 结算金币 → 商店 → 下一关 …… 第 3、6 关后先领首领奖励（3 件罕见或稀有神器选 1，可跳过）再进商店 → 第 9 关通关 → 可选继续**无尽模式**。

生命 40，整局共用。生命耗尽则本局结束；本地记录最好成绩（通过的关数、总分）。

## 一关

**弱引导**：停手 5 秒后，棋盘上提示一步交换（那两格朝对方轻轻顶两下，循环到有操作为止）。优先提示能亲手做出炸弹的交换（五连 > 3×3 > 直线），其次是普通三消；只看交换当下形成的匹配，不预测连锁。

| 项目 | 规则 |
| --- | --- |
| 棋盘 | 10×10，四种方块：红圆、蓝方、黄三角、绿菱形（出现比例 30 / 25 / 25 / 20，沿用旧权重，待定） |
| 步数 | 5 回合 × 每回合 3 步 = 15 步；步数用完自动进入下一回合 |
| 交换 | 只能交换能形成消除的相邻两格；炸弹与任意相邻格交换即引爆；两枚炸弹交换发动组合技；点两下炸弹原地引爆 |
| 过关 | 累计分数达到目标**立即过关** |
| 未达标 | 15 步用完仍未达标：按差距比例扣生命（差 20% 扣最大生命的 20%，向上取整），然后照常进入下一关 |
| 死局 | 没有可走的交换也没有炸弹时自动重排 |

## 计分

每一步的分数 = **基数 × 倍率**。

- **基数**：这一步第一次下落之前（主动阶段）清除的方块，每块计“方块基数等级”；被炸弹炸掉的，再加“该类炸弹的爆破等级 − 1”。
- **倍率**：由连锁决定。第一次下落之后（被动阶段）清除的每一格都往倍率槽里填：5 段依次需要 6 / 10 / 14 / 18 / 22 格，每段填满倍率 +1，段内按比例、取到 0.1；5 段用完后**不封顶**，每 22 格再 +1。
- **爆破等级加成**：这一步引爆过的每类炸弹，按“爆破等级 − 1”各给倍率 +0.1。
- **神器**：分“加成”和“乘成”两层。先把连锁、爆破等级和所有神器的加成相加，再乘上所有神器的乘成；“独行”则把基数 ×2。加法和乘法各自可交换，所以神器的持有顺序不影响结果。首领规则“低压”的 ×3 封顶限制的是最终倍率。

## 炸弹

| 炸弹 | 怎么做出 | 范围 |
| --- | --- | --- |
| 直线（横 / 竖） | 四连 | 整行或整列 |
| 3×3 | T 形、L 形 | 周围 3×3 |
| 五连 | 五连 | 棋盘上某一种颜色的全部方块 |

- **产弹格**：亲手交换形成的消除，产在交换的落点；连锁中形成的消除，T、L、十字产在横竖交叉的拐角，直线产在刚落下来把它凑齐的那一格。
- **爆破等级**：每关从商店买到的等级开始，本关每引爆 12 / 9 / 3 枚（直线 / 3×3 / 五连）该类炸弹升一级，下一关重置。

## 首领关

第 3、6、9 关（无尽模式里每三关）为首领关，带一条规则。规则按局种子抽取，不与上一个首领关相同，**开关前在路线页公开**。

| 规则 | 效果 |
| --- | --- |
| 倒悬 | 整关重力向上，新方块从下方补入 |
| 色封 | 一种颜色本关不计基数（照常消除、照常引发连锁） |
| 石阵 | 开局 6 块石块，不能交换，只能用炸弹炸掉 |
| 低压 | 倍率封顶 ×3 |
| 冷却 | 本关爆破等级不上升 |
| 哑火 | 本关所有神器失效 |

## 道具

在关内随时使用；造成的消除照常计分，可以直接达标。使用道具不消耗步数（2026-10-06 定），但本回合必须还有步可走。

| 道具 | 价格 | 效果 |
| --- | --- | --- |
| 锤子 | 4 | 砸掉任意一格：砸到炸弹就引爆，砸到石块就清掉 |
| 手套 | 6 | 任意两格相邻互换，不要求能消除 |
| 炸药包 | 10 | 把一个普通方块变成五连炸弹 |
| 雷管 | 8 | 引爆棋盘上所有炸弹 |
| 洗牌 | 5 | 整盘重排，炸弹和石块不动 |

## 任务

开关前在路线页从**一易一难**两条任务里选一条（类别不同，按局种子固定）。本关里做到就算完成，**没达标也照发奖励**；“速通”只能在达标时完成。

| 奖励 | |
| --- | --- |
| 易 | 3 金币（首领关 5） |
| 难 | 一件没有的随机神器（普通 70 / 罕见 30）；神器栏满时改给 10 金币 |

| 任务 | 易 | 难 |
| --- | --- | --- |
| 一步连锁 N 层 | 8 | 10 |
| 一步清除 N 格（含连锁） | 130 | 165 |
| 一步倍率达到 ×N | 6–7（随关卡） | 8–10 |
| 一步拿到目标分的一定比例 | 33% | 50% |
| 本关做出 N 枚五连炸弹 | 3 | 6 |
| 本关引爆 N 枚炸弹 | 30 + 关数 | 48 + 2 × 关数 |
| 提前 N 步达标 | 4 | 8 |

门槛按熟练自动玩家每关的自然分布定：易约一半顺手完成，难约两成。首领规则让某类任务做不到时，这一关不抽它（“低压”关不出倍率任务）。

## 神器

**神器栏最多 6 件**。在商店和首领奖励时可以在神器栏里**半价卖出**（向下取整）。栏满时不能再买或再领，要先卖掉一件，首领奖励也可以跳过。同一件神器一局最多持有一件。

| 来源 | 稀有度 |
| --- | --- |
| 开局三选一 | 只出普通 |
| 首领奖励三选一（第 3、6 关后；无尽模式每个首领关后） | 只出罕见、稀有（25 : 5） |
| 商店（每关后 2 件） | 普通 70 / 罕见 25 / 稀有 5 |

首领规则“哑火”让本关所有神器失效（包括玻璃炮少 1 步的代价；香蕉不烂、冰淇淋不化、金币类不给、勋章不计）。卖掉神器时它的进度清零。
