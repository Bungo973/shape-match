# 战斗与成长规则（草案 v0.13）

本文是实现和试玩的统一规则源。**已确定的核心规则**：主动消除给基数，被动消除只提高倍率，按“基数 × 倍率”结算。所有具体数字均为初始调参值，改动需记录原因和版本。

## 1. 基础状态

| 项目 | 初始规则 |
| --- | --- |
| 棋盘 | 10×10（2026-09-29 由 8×8 改为 10×10，见 [BOARD_SIZE_DECISION](BOARD_SIZE_DECISION.md)）；攻击 30%、护盾 25%、毒气 25%、催化剂 20% 的生成权重 |
| 主角 | 炼成师（地下寻宝探险者）；最大生命 40，初始生命 40，初始护盾 0 |
| 回合 | 每个玩家回合 3 AP；可提前结束；AP 不跨回合保留 |
| 交换 | **只允许形成匹配的交换**（2026-09-30 定），每次消耗 1 AP；不成匹配的交换无效，不耗 AP，方块弹回原位。炸弹与相邻普通方块交换，在炸弹的落点直接引爆（`CB` 按对方颜色清除）；换过去的普通方块若在它的落点成匹配，同一主动阶段一并结算（先匹配、再引爆，清除取并集，这次做出的炸弹保留在落点不被波及）。两枚相邻炸弹即使同类也可交换发动组合技 |
| 点燃 | 花 1 AP 单独引爆任意无属性炸弹，不移动方块；属于主动触发 |
| 死局重排 | 场上没有炸弹、也没有可匹配的交换时自动重排：不耗 AP，按种子只打乱普通方块（石块、炸弹不动），重排后无现成三连且至少有一步可走。在开战、每次行动后与石化后判定（`src/engine/shuffle.ts`） |
| 护盾 | 先于生命承伤；**只挡本回合**：敌人行动结算后清空，不带入下一场战斗；上限 40（2026-09-29 由“永久保留、上限 20”改为每回合清空，参数 `playerShieldRetain`、`playerShieldCarryOver`，见 BALANCE_LOG） |
| 毒气条 | 眩晕阈值 = 敌人最大生命 × 25%（四舍五入）；达到阈值触发一次眩晕，详见第 4 节 |
| 催化剂充能 | 最多 5 层，每层给攻击、护盾、毒气基础值各 +1，跨行动和战斗保留；下一次**主动清除至少一枚有色普通方块**的行动结算时全部消耗；交换、点燃或组合均适用 |
| 倍率 | **连续倍率槽**（2026-09-28）：从 ×1 起分 5 段，每段填满倍率 +1，各段所需被动清除数依次为 6/10/14/18/22，即 `P`=6、16、30、48、70 时达到 ×2～×6；段内线性上涨，向下取到 0.1；封顶 ×6（参数 `multiplierSegments`） |

生成新棋盘时不允许初始三连，且至少有一步可走（否则按死局重排）。只有形成匹配的交换、与炸弹有关的交换和点燃有效；选中同一格、非相邻格、交换两个同色普通方块或不成匹配的交换都不改变棋盘，也不消耗 AP。**相邻两枚无属性炸弹**即使类型相同也允许交换发动组合技；炸弹与普通方块交换在落点引爆。（2026-09-30 之前任意相邻交换都有效、未消除交换保留新排列，可用于铺路；已取消。）

## 2. 一次行动的结算顺序

**已确定**：每次交换或点燃都立即独立处理；上一行动的掉落、连锁和效果全部结束后，玩家才可进行下一次行动。一个回合中的最多 3 次行动不合并结算。战斗中不高亮建议交换位置、不预览主动消除或后续连锁。

1. 玩家选择相邻交换或点燃一枚炸弹，均消耗 1 AP。单独点燃、两枚炸弹直接交换、炸弹与普通方块交换（在落点引爆）均无需三连便主动发动；炸弹与普通方块交换时，换过去的普通方块若成匹配，先结算该匹配再引爆，这次做出的炸弹不被本次爆炸波及。两枚普通方块的交换必须形成匹配，否则为无效操作。
2. 在**第一次重力移动之前**，依次处理玩家交换造成的匹配、手动点燃、炸弹组合和爆炸接力。实际清除的每个有色方块按基础方块种类分别计入**主动消除** `A攻击、A护盾、A毒气、A催化剂`；任何无属性炸弹自身都不进入颜色基数。同一方块被多个爆炸波及也只计一次，主动清除经过嵌片格照常触发嵌片。一次交换若形成多个独立产弹匹配组，每组各生成一枚；炸弹先出现在**属于该组的参与交换方块的交换落点**，两枚参与交换方块各有自己的落点。被保留并改造成炸弹的方块不算清除。**升级表**（2026-09-29，取代 2026-09-28 的“特殊匹配 ×2”）：主动清除一块有色方块计入该色“方块等级”份基数（初始 1 级）；**爆破等级**（2026-09-30，取代“亲手做出炸弹加基数”）：直线、3×3、五连各有本场爆破等级，每场从炸弹升级等级开始；本场每引爆 12／9／3 枚该类炸弹（含接力、组合技的两枚与改造出的炸弹，参数 `bombHeatEvery`）升一级，新等级从下一次行动起生效。n 级时，该类炸弹炸掉的每块有色方块多计 n − 1 基数；同一格被多个爆炸覆盖取最大，组合技取两枚中较高的等级。被动阶段不受等级影响。详见 [BLOCK_BUILD](BLOCK_BUILD.md)。主动队列处理完后才开始第一次重力移动和补充。
3. 第一次重力移动后，自然形成的所有匹配、炸弹生成、被爆炸或嵌片引爆的炸弹，以及爆炸接力都保持**被动来源**。普通匹配不能引爆炸弹，因此没有嵌片时被动阶段只有匹配与产弹；被动爆炸来自易燃物质、火药等嵌片。完整的阶段与波次顺序见[触发引擎与消除结算](INSERT_DESIGN.md#触发引擎与消除结算2026-09-27-已确定)。被动匹配若生成炸弹，将其留在匹配组沿当前重力方向最远的一格：向下取最下行，向上取最上行；同一行并列时取最左列。产弹格不计清除，其余实际被清除的每个方块（包括任何无属性炸弹）只累计到总数 `P`，不触发方块颜色的基数或催化剂充能。若被动爆炸触发火药嵌片，其连带清除也只计入倍率。炸弹与普通方块一样随重力移动；嵌片固定在棋盘格。重复移动、补充和被动清除直到棋盘稳定；即使被动阶段的直线炸弹引爆 `CB` 并清除一种随机方块，这些清除仍只增加 `P`。默认重力向下；最终 Boss 可施加重力向上反转的负面状态，届时方块向上填补，新方块从下边缘补入。首版不使用左、右方向，具体机制见[重力异常设计](GRAVITY_DESIGN.md)。特殊方块类型和连锁约定见 [SPECIAL_TILES.md](SPECIAL_TILES.md)。
4. 按倍率槽计算 `M`：设 `P` 落在第 `i` 段（从 0 起）、该段已填 `x` 格、该段需 `n` 格，则 `M = 1 + i + x/n`，向下取到 0.1，封顶 ×6。例如 `P=0` 为 ×1，`P=5` 为 ×1.8，`P=6` 为 ×2，`P=11` 为 ×2.5，`P=16` 为 ×3。每段所需格数递增，长连锁仍有回报，高倍率留给构筑。神器或敌人“提高／降低一档”即倍率 ±1。“连锁透镜”等神器先修正倍率，再处理已生效的敌方倍率状态（见 [ENEMY_DESIGN.md](ENEMY_DESIGN.md)）。被动消除只通过 `P` 影响 `M`，火药嵌片由被动爆炸触发的连带清除也计入 `P`。
5. 若本次行动在第一次重力移动前**主动清除了至少一枚有色普通方块**（含被改造为炸弹的有色方块），读取行动开始前存储的催化剂层数 `C` 并清空；否则 `C=0`，旧充能保留。炸弹无属性，爆炸范围内若只有炸弹、没有有色方块，本步没有颜色基数，也不消耗充能；这种情况需要整片范围都是炸弹，实际极少出现。统计主动消除触发的、未被敌人压制的嵌片基础值 `E攻击、E护盾、E毒气`。三个效果基础值为 `B攻击=A攻击+C+E攻击`、`B护盾=A护盾+C+E护盾`、`B毒气=A毒气+C+E毒气`。即使本步未主动消除某一类，该类也可以因旧充能或嵌片得到基础值。催化剂不为自己加基数。
6. 核心效果为 `攻击=B攻击×M`、`护盾=B护盾×M`、`毒气=B毒气×M`，四舍五入到整数。神器按其描述的时机修正基数、倍率或最终效果；UI 逐项列明来源。
7. 本步结算分为 `S=(B攻击+B护盾+B毒气+A催化剂)×M`（四舍五入），累计到本局总分，仅用于反馈和结果页，不作为货币或伤害。嵌片的基础值已包含在 `B` 内；神器带来的最终效果加成不计入结算分。
8. 本步主动消除的催化剂每满 3 个，获得 1 层**新充能**，最高存到充能上限 5 层（`chargeCap`）。新充能不会被本步使用；被动消除的催化剂只贡献 `P`。若本步使用了旧充能又生成新充能，结算后保留新充能。
9. 护盾增加至上限，攻击先扣敌人护盾再扣生命（如果该敌人有护盾），毒气增加至阈值判定。击杀立刻结束战斗，不再执行剩余玩家行动或敌人行动。若战斗继续，显示 AP 和当前敌人意图。

**Boss 重力异常时机**：若 Boss 已成功施加向上反转，从下一个玩家回合起暂定持续 3 个完整玩家回合。该回合内的每次行动结算都使用向上重力；玩家提前结束回合也消耗一个持续回合。每个受影响回合结束且所有行动结算完成后减去 1 回合，第三个回合结束后恢复向下。状态生效期间 Boss 不再选择重力反转意图，也不会刷新或叠加时长；状态结束后才能再次选择。毒气眩晕若取消了 Boss 施加异常的意图，则不启动这段持续时间。

**例子**：本步主动消除 3 攻击和 3 催化剂，下落被动消除 16 格，步前存有 1 层充能，且 1 个被主动清除的攻击方块位于锋刃（攻击嵌片）覆盖格。倍率 ×3（填满前两段 6+10 格）；基础值为攻击 `3+1+2=6`、护盾 1、毒气 1；本步结算分为 `(6+1+1+3)×3=33`；核心效果为伤害 18、护盾 3、毒气 3。步后由主动催化剂存入 1 层新充能。被动消除即使经过其他嵌片格，也只影响倍率。

**混合种类炸弹例子**：若主动炸弹清除 3 个攻击和 2 个护盾，随后第一次下落后被动匹配又清除 5 格，且没有旧充能、嵌片或神器加成，则攻击基数为 3、护盾基数为 2、`P=5`，倍率 ×1.8，最终造成 `3×1.8=5.4→5` 伤害并获得 `2×1.8=3.6→4` 护盾。被动阶段清除的颜色不会再增加任一基数。

**直线炸弹引爆五连炸弹例子**：主动横向炸弹清除 2 个攻击并波及 `CB`，`CB` 随机选中护盾，继续清除 4 个护盾；第一次下落尚未发生，因此攻击基数为 2、护盾基数为 4，`CB` 自身不增加基数。若相同的横向炸弹是第一次下落后才被引爆，这些清除（包括 `CB`）全都只计入 `P`。

### 特殊方块扩展（讨论稿）

横向 `H`、竖向 `V`、3×3 `A` 与五连 `CB` 全是独立的无属性炸弹，产弹时保留格不计清除，炸弹本身不提供颜色基数。玩家可花 1 AP 单独点燃任意炸弹，或花 1 AP 交换相邻炸弹发动原有组合。`CB` 与普通方块交换按对方类型清除；与无属性 `H/V/A` 交换时，按用户确定的规则从当前棋盘现存基础方块类型中随机选择目标，再批量改造并引爆；`CB` 单独点燃或被其他炸弹波及时也随机选现存类型。具体范围、锚点、产弹优先级、改造计数与组合矩阵统一见[无属性炸弹规则](SPECIAL_TILES.md)。

## 3. 回合与敌人意图

- 战斗开始时展示当前敌人意图。玩家可以交换、点燃炸弹至 AP 为 0，或提前结束回合。
- 玩家回合结束后，若敌人未死亡，尝试执行已展示的意图；敌人回合末先结算毒气控制进度衰减，再产生并展示下一次意图，玩家 AP 恢复到 3。
- 敌人直接攻击先扣主角护盾，再扣生命。生命归零立即结束本局。
- 敌人护盾**跨回合保留**，直到被攻击削减（主角护盾则在敌人行动后清空）；带攻击的意图被眩晕取消时，已累积的蓄力加成一并作废；只取消单独的蓄力意图时，本次不增加加成，之前的加成保留。
- 首版意图类型：`攻击 N`、`防御 N`、`蓄力（下次攻击 +N）`。首领可组合其中两项，但必须完整预告。
- 敌人的行动序列使用固定模板加少量随机变化；随机结果在玩家行动前确定并显示，不能在玩家最后一步后暗改。

## 4. 毒气与眩晕

- 毒气是对当前敌人的眩晕进度，阈值为敌人最大生命的 25%（四舍五入，至少 1），血量越高越难控制；战斗结束清零。进度及阈值始终可见。回合末衰减量为阈值的 1/6（四舍五入，至少 1）。
- 玩家结算使毒气达到或超过阈值时，给敌人添加 1 次待生效眩晕，毒气进度归零。一次玩家回合至多挂上 1 次眩晕；本回合后续获得的毒气不积累，避免无限控制。
- 该回合结束时，眩晕取消敌人已经展示的**整次**意图，包括攻击、防御和蓄力，然后消耗眩晕状态。完成回合末毒气衰减后，再展示下一次意图。
- 每个敌人回合结束时，敌人尚存的毒气控制进度减少一部分，最低到 0；敌人被眩晕而跳过意图时，这个回合末衰减仍发生。衰减量是待试玩参数，并在敌人毒气条旁显示。普通眩晕仍按上一条规则把进度归零；（原密封毒瓶已于 2026-09-30 删除）可让眩晕后保留低于阈值的一部分进度，留存进度也会受到这次回合末衰减。
- 若敌人在眩晕前被击杀，立即结束战斗并进入战后流程，不消耗额外行动。
- 改变阈值的神器只能影响后续毒气判定；它不会追溯触发一次眩晕。

## 5. 嵌片（种类与触发方式待定）

> **2026-09-29**：嵌片已从一局流程中移除，战后奖励改为升级三选一、营地升级改为任选一项 +1 级，规则见 [BLOCK_BUILD](BLOCK_BUILD.md)「奖励与营地」，实现于 `src/engine/rewards.ts` 与 `src/engine/run.ts`。本节保留作历史记录。

- 嵌片初始是四个正方格组成的相连形状；首版从 `I、O、T、L、S` 形状池抽取，可旋转 90°。同一块嵌片的所有格同效，没有核心格；升级后可多于四格。候选见[嵌片种类设计](INSERT_DESIGN.md)。
- 每场非最终战胜利后，都从 3 块候选嵌片中选 1 块存入随身匣。候选不要求当前棋盘马上有空位。**只在非战斗阶段**可从随身匣选择嵌片、按 90° 旋转、预览落位并确认嵌入；进入战斗后棋盘布局锁定，战斗中不能嵌入。
- 所有覆盖格必须全在棋盘内且不与已有嵌片重叠；同时最多安装 6 块，其余留在随身匣。**嵌入即固定**：已安装嵌片不能直接移动、旋转或取出，也不随方块下落移动；升级添加一格是唯一的原位扩张方式。取出只由第 3、6 战后的商店服务或明确允许的特殊事件执行；取出后回到随身匣，不会销毁且保留扩张后的形状，此后可再次旋转并嵌入合法位置。
- 每场非最终战后的营地可在**升级一块拥有的嵌片**与**休息**之间选一次；升级只给该嵌片增加一个正交相邻的空格，不能越界、重叠或使形状断开。已安装的原位扩张，原有格不动；库存中的升级后仍可旋转嵌入。升级费用与最大面积待定。普通嵌入不占用营地选择。其他金币用途和战后顺序见 [MAP.md](MAP.md)。

**普通款三种基数嵌片（2026-09-27 确定触发条件）**：锋刃、壁垒、毒囊分别在覆盖格上主动清除**同色**的攻击、护盾、毒气方块时，每格提供对应基数；异色方块与炸弹不触发。首版十二种嵌片的精确规则见[首版嵌片池](INSERT_DESIGN.md#首版嵌片池2026-09-27-名单已定)。被动消除不产生这些基数。高档嵌片以局部产弹、引爆和扩大清除为主，不附带负面代价；各档升级都只增加一格覆盖范围，具体候选见[嵌片设计](INSERT_DESIGN.md)。结算面板应按实际类型列出嵌片触发次数与贡献。

**火药嵌片候选**：一次炸弹爆炸只要波及任意覆盖格，就连带清除该嵌片所有覆盖格上的方块。同一爆炸命中多格只触发一次；炸弹位于嵌片格内也会触发。连带清除继承该爆炸的主动或被动来源，首次下落后触发时只增加倍率。连带清除中的炸弹照常引爆，同一方块只计一次；嵌片追加的清除本身不算新爆炸。

## 6. 神器初始池

## 7. 战后成长与一局结构

- 一局固定 9 战：`（小怪 → 小怪 → 大怪）×2 → 小怪 → 小怪 → 最终 Boss`。大怪按精英敌人处理。第 3、6 战后的营地各接一个事件和一个商店；没有分支路线。详见 [MAP.md](MAP.md)。
- 开局从 3 件候选神器中选 1 件。每场非最终战胜利都结算金币并选 1 块基础嵌片。第 3、6 场精英额外从 3 件神器中选 1 件；两个随机事件有机会提供神器，第 3、6 战后的商店可出售神器。同名神器不重复进入候选。小怪的直接掉落不含神器。
- 非最终战领奖后进入营地，选择**升级或休息之一**；升级为花金币任选一项方块或炸弹 +1 级（2026-09-29 起，见 [BLOCK_BUILD](BLOCK_BUILD.md)）。最终 Boss 胜利直接进入结果页，不发金币或其他战后奖励。
- 战后保留生命、催化剂充能、金币、已安装/未安装嵌片和神器，护盾清零；敌人相关毒气和眩晕清零；新战斗 AP 恢复为 3。
- 首版敌人的生命、攻击等具体数值由可配置关卡表给出，以试玩校准。精英与最终 Boss 除数值外至少增加一种可预告的意图组合；最后一战必须明显考验至少两项已获得的构筑能力。

## 8. 可复盘性

每局生成并保存随机种子。相同版本、相同种子、相同玩家选择应得到相同的棋盘、掉落、敌人意图和奖励候选。战斗日志至少记录交换坐标或点燃目标、主动与被动清除数量、倍率、充能消耗/产生、嵌片触发和最终效果，供开发与试玩复盘。
