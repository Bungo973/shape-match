# 神器设计空间（非数值草案）

神器是整局持续能力。玩家**开局先选一件**，之后可以从第 3、6 场大怪奖励、随机事件以及商店继续获得；没有固定的持有数量上限，同名神器整局只获得一次。它可以改变玩家如何看待方块、嵌片、敌人和战后决策；不限定为“加基数”或“加倍率”。**神器自动触发，不增加手动施放、选择爆炸方向等主动操作。**具体强度通过试玩调整。

## 五类设计方向

| 方向 | 能改变什么 | 概念示例 |
| --- | --- | --- |
| 方块特性 | 主动消除某种方块时，改变它的作用方式 | **穿甲针**：攻击对敌人护盾造成额外伤害，但护盾仍先于生命承伤；**密封毒瓶**：毒气眩晕后保留部分控制进度，留存进度仍受回合末衰减影响 |
| 特殊方块联动 | 改变特殊方块的生成、引爆或连锁方式 | **过载引线**：直线炸弹引爆范围扩大，但本次不能获得护盾；**滞留胶囊**（未入选）：被动连锁不消耗特殊方块，但其下次主动引爆不触发嵌片 |
| 嵌片联动 | 改变嵌片的触发条件、形状价值或战后布置 | **共振底座**：同一次行动触发两块不同嵌片时提高本次倍率；**锁位共鸣器**：相邻的两块已安装嵌片被同一步主动消除触发时，彼此增强 |
| 战斗怪奇规则 | 改变眩晕、防御或回合节奏 | **回响钟**：毒气取消敌人意图时，下一回合获得额外机会；能力自动触发 |
| 战后与经济 | 改变金币与奖励 | **拾荒眼镜**：重掷嵌片候选后保留一个旧候选；**藏宝图残页**：嵌片奖励永久多展示一个候选，仍只选一块 |

这些是机制方向，正式名单见下文“首版神器池”；名称、触发次数、代价和强度都可以改。穿甲针、密封毒瓶、共振底座、过载引线、拾荒眼镜与额外奖励选项的方向已得到认可，具体规则仍待试玩。**定向罗盘**和**空白账本**已从候选池移除。**折叠药箱**暂缓，待休息区的用途与选择流程设计后再评估。因为一局有开局、精英、事件和商店多个来源，首版池建议至少 12 件，避免候选重复和商店空架。

原嵌片候选**折光导轨**暂移入神器灵感池：直线炸弹的爆炸路径经过嵌片时可折射出垂直清除线。若正式采用，须先规定炸弹自身就在嵌片格时的触发、一次爆炸最多折射几次，以及折射线不能递归折射。未解决这些边界前不进入首版神器池。

## 设计边界

1. **持续生效，明确时机**：神器不需要手动使用，也没有一次性消耗；不增加战斗中的主动技能按钮或方向选择。描述要能说清何时触发、持续多久、与哪些效果叠加。
2. **核心公式可读**：主动消除产生基数，被动消除只提高倍率。神器可以改变基数、倍率、触发条件或战后规则，但被动方块的颜色仍不产生自身攻击、护盾、毒气或催化剂效果。
3. **鼓励新选择**：优先选择会改变玩家行动、特殊方块使用或嵌片布局的神器；只有更大数字、没有新决策的能力不占满稀有奖励池。
4. **避免死循环**：额外消除、返还行动力、重复触发等能力须有明确的每回合或每步次数上限；不让同一神器由自身效果反复触发。
5. **特殊神器允许负面代价**：代价要和收益一样持续、明确、可预告，不能在领取后才暴露隐藏惩罚。领取前展示触发条件、收益、代价及持续时间；结算日志要能追溯双方贡献。

重力改变属于[最终 Boss 的负面状态](GRAVITY_DESIGN.md)，不进入神器池。

## 已确定的风格与待办

首版混合可靠强化与带条件、带负面代价的特殊神器。代价型神器可涉及基础方块、[特殊方块](SPECIAL_TILES.md)、嵌片、敌人意图或战后经济，但不能暗改“被动消除只提高倍率”的基础规则。下一步补全正式神器池，并检查每件神器是否带来不同决策，而不只是更大的数值。

### 引擎实现时补充的口径（2026-09-28）

- **穿甲针**同样作用于反应线圈的反击：两者都是对敌人造成伤害，先扣护盾再扣生命。
- **不稳定引信**的“主动引爆的炸弹”包括单独点燃、接力、改造出的炸弹，以及炸弹组合技中被消耗的两枚。回合末的自伤先于敌人行动结算，可以致死。
- **连锁透镜**的 `P≥3` 判定使用经不稳定引信修正后的 `P`。
- **锁位共鸣器**只影响以“被爆炸波及／扫到”为条件的嵌片；第一批中只有火药嵌片，第二批再加入齐射与爆裂晶体。
- **倍率档位**：神器提高的档数先合并并封顶在 ×8，敌方倍率侵蚀再降一档，最低 ×1。例如 `P=9` 且持有连锁透镜、又被侵蚀时为 ×4。
