# 棋盘与嵌片的视觉规范及 AI 提示词

当前[整盘层级样张](../assets/reference/board-insert-layering-concept.png)已能让 T 形覆盖范围和普通方块同时可见，可作为层级参考。右下银色虚线更像**放置预览**；战斗中已安装嵌片应使用连续外轮廓，虚线只用于非战斗阶段的拖放预览。图中角落的通用箭头与菱形能帮助找位置，却不足以说明嵌片是什么效果；正式版改用各嵌片的独立效果标志。样张不是可直接使用的棋盘文件。

新收到的[带边框空棋盘底图](../assets/candidates/first-batch/board-empty-framed.png)可以作为固定 8×8 棋盘的底层，网页再叠加准确的格线和方块。[纯石纹图](../assets/candidates/first-batch/stone-texture-optional.png)只有普通地板质感，**不是嵌片**；目前也不必额外使用，因为空棋盘底图已经有类似石纹。此前要求 AI 生成“嵌片底纹素材”容易产生这类通用石纹，是提示词方向不准确；嵌片覆盖层改由程序绘制。

## 共同的视觉结构

棋盘是 8×8。嵌片**固定在棋盘格位**，普通方块和炸弹在它上面交换、下落；已安装嵌片可以原位增加覆盖格，因此不能把某种 T／L 形做成一整张不可拆的图片。

实际项目至少拆成四层：①空棋盘底图与网页绘制的 8×8 格线；②按格位绘制的嵌片浅色覆盖、每格效果角标和整块外围轮廓；③可移动的普通方块与炸弹图标；④选择、触发、压制和清除反馈。第 ② 层的几何由嵌片当前覆盖坐标计算，旋转和升级后自动重画，不能用整盘截图或固定形状 PNG 代替。

程序中每块嵌片保存一组**相对格坐标**，例如 T 形为 `(0,0)、(1,0)、(2,0)、(1,1)`；安装后加上棋盘位置。旋转时转换这些坐标，升级时新增一个与现有覆盖格正交相邻的坐标。绘制时，每个覆盖格获得相同的浅色层和角标；某条边若没有同块嵌片的相邻格，才绘制该条**外围边线**。因此任何形状增加一格都能自然延伸，没有“核心格”图片。

建议由下到上绘制：**深色格底 → 嵌片的浅底纹 → 整块嵌片的连续外轮廓与每格角落的小效果标志 → 普通方块／炸弹 → 选中、清除与触发反馈**。嵌片边界沿覆盖格的外围走，不给每格都画一圈亮框；内部保留棋盘格线。所有覆盖格的底纹和标志相同，不设置视觉核心格。

原型的起始比例：每格约 72–80px 时，方块图标占格内约 65–75%，嵌片角标占格宽约 18–22%，嵌片底纹只比普通格底略亮，连续外轮廓约 2px。具体像素以真实页面缩放测试为准。**方块和炸弹保持原色、原对比度**；不要通过压暗方块来显露嵌片。

不同嵌片通过效果角标、底纹笔触和外围线型识别；颜色只做辅助。安装后可在每个覆盖格重复同一小标志，避免单个“大徽章”被误解为核心格。敌人压制嵌片时只改变嵌片外轮廓并加失效标记，不压暗棋盘方块。触发时沿嵌片外轮廓短促发亮，方块清除动画仍在上层。棋盘调整阶段的合法放置预览用虚线外轮廓；战斗中不显示预览或走法提示。

## 提示词 1：整盘视觉验证稿

上传[战斗基调样张](../assets/reference/battle-tone-concept.png)、现有普通方块图标和[炸弹候选](../assets/candidates/first-batch/bomb-line-horizontal.png)作为画风和图标参考。这张只用于判断层级与清晰度，**不直接当可玩的棋盘资产**；AI 可能画错格数与嵌片形状。

> 绘制一张桌面三消游戏的棋盘视觉设计稿，正视角、清楚的 8×8 正方形棋盘，共 64 个大小一致的格子。画风沿用上传的地下探险游戏参考：深蓝灰色石质格底、克制的铜色边框、鲜明的独立方块图标。棋盘上有攻击短刃、蓝色盾形护符、绿色毒雾瓶、紫色催化晶，也有少量深色橙铜炸弹。方块图标清楚、完整、饱和，始终是每格最醒目的元素。
>
> 在棋盘格底上、方块图标下表现两块已安装嵌片：一块连续的四格 T 形嵌片，另一块连续的五格 L 形嵌片，两块互不重叠。嵌片是一层嵌在格底里的浅底纹，不是盖在方块上的实心拼图。每块嵌片只有沿整体外周连续的一圈细亮边，不在内部每格重复画粗边；覆盖格角落各有同样的小效果标志，没有核心格。两块嵌片通过不同的角标、底纹方向和外边线样式区分，不能只靠颜色。内部棋盘格线仍可见。每格中心的普通方块或炸弹保持完整亮度和形状，不被嵌片遮挡。
>
> 不显示人物、敌人、状态栏、文字、数字、走法提示、交换箭头、大片发光遮罩或爆炸特效。这是可读性设计稿，不是最终游戏贴图。

## 备选提示词：单格底图

现有空棋盘底图若无法与精确的网页格线对齐，再考虑单独生成**一格**并重复排成 8×8；目前无需继续生成。

> 独立的 2D 游戏棋盘空格底图，正方形画布，正视角。深蓝灰色石板与少量暗铜镶边，中央平整安静，纹理和高光都很弱，为明亮的三消方块图标留出清晰背景。四条边规则、可与同款格子紧密排列成 8×8 棋盘；格位边界可见但不抢眼。沿用上传的战斗基调图的卡通游戏质感。没有方块图标、炸弹、嵌片、符号、文字、数字、强烈投影或场景背景。

嵌片无需再生成整块底纹图片。其形状、边界、低透明度底色、压制状态和扩张都由代码维护；AI 只为各嵌片制作独立的[效果角标](ASSET_PLAN.md)。

## 接受标准

1. 缩到实际桌面显示大小，玩家能迅速指出哪些格子属于同一块嵌片，并分清相邻两块嵌片。
2. 同样大小下，四种普通方块和四种炸弹仍比嵌片更醒目；图标的颜色与外形不被改写。
3. 升级增加任意合法一格后，底纹、角标和整体外轮廓可自动延伸，不依赖重新生成整块图片。
4. 嵌片压制、合法放置预览和触发闪光各有独立状态，但战斗状态下不出现走法提示。
