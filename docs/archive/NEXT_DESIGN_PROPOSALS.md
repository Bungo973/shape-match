# 下一轮设计提案（供讨论，不作为已确定规则）

本稿只补首版开工前最值得看的机制与体验问题。生命、伤害、金币、掉率和动画时长均留给原型测试。已经确定的路线、计分与操作规则仍以 [PRD](PRD.md)、[战斗规则](../GAME_RULES.md)和[地图与营地](MAP.md)为准。

## 1. 首版嵌片池：规则唯一，覆盖面成长

同效果一局只获得一块；战后仍是稳定／构筑／惊喜三选一。现有八种加四个新候选组成十二种效果，足以让八次非最终战奖励在后期继续给出选择。下表档位已于 2026-09-27 采纳为首版名单，精确规则见[首版嵌片池](../INSERT_DESIGN.md#首版嵌片池2026-09-27-名单已定)；掉率仍待试玩。

| 暂拟档位 | 效果与构筑作用 |
| --- | --- |
| 普通 | 锋刃、壁垒、毒囊、催化盐：给攻击、防御、控制与储能稳定底盘 |
| 稀有 | 土质火药、易燃物质、火星陶：让三连产弹、落点自动点火、直线炸弹追加 3×3 |
| 高级 | 火药嵌片、齐射嵌片、震裂石：整片清除、多线齐射、放大 3×3 |
| 完美 | 爆裂晶体、星火矿脉：把覆盖格批量变成炸弹并连爆 |

**筛选法**：对每块嵌片实际试着加一格。若新增格不能明显扩大触发机会、清除范围或产弹机会，就修改或淘汰该规则。稀有度决定获得机会和爆发上限，不赋予负面代价。

## 2. 神器先做几种真正不同的选择

神器持续整局生效，满足条件便自动触发，可以有公开的代价；以下先保留用户认可的方向。定向罗盘、空白账本已移出；折叠药箱等休息联动待休息区流程确定后再评估。

| 候选 | 改变玩家什么决定 |
| --- | --- |
| 穿甲针 | 攻击对护盾有加成，仍先扣护盾再扣生命；鼓励攻击构筑对付石甲敌人。 |
| 密封毒瓶 | 毒气成功取消敌人意图后保留部分控制进度；剩余进度照常在敌人回合结束时衰减。 |
| 共振底座 | 同一步触发两种不同嵌片时提高本次倍率；不改变主动与被动的计分来源。 |
| 过载引线 | 直线炸弹爆炸范围扩大，但该次行动不能获得护盾；领取前明确展示收益与代价。 |
| 拾荒眼镜 | 重掷嵌片三选一时保留一个旧候选，帮助玩家继续构筑而非完全重来。 |
| 藏宝图残页 | 每次嵌片奖励自动多展示一个选项，但仍只取一块；具体名称和稀有度待定。 |

每件正式神器须明确：触发时机、是否限每行动／回合一次、与哪些嵌片互动、何时结算代价。不要让神器把第一次下落后的被动清除改算为颜色基数。

## 3. 敌人给构筑出题，先把压制语义统一

第 3 战倍率侵蚀、第 6 战嵌片压制和最终 Boss 重力反转已经有草案，见[敌人行为](ENEMY_DESIGN.md)。嵌片压制要暂停目标嵌片的**整条规则**，包括产弹、自动点火和扩散，不只暂停基础值；标记目标后不得暗换。

作为第 7 或第 8 战小怪的备选，可以试做“洒水矿车”意图：预告一行，使该行炸弹在下一玩家回合无法**手动**点燃，但仍可交换或被其他爆炸接力引爆。玩家可改用别的引爆路线，毒气眩晕也能取消洒水。若试玩发现它在没有走法提示的棋盘上过于难读，就保留现有常规意图组合，不把它加入首版。

## 4. 三个结算边界，原型前定口径

1. **匹配归组（已采纳，正式规则见[匹配识别与归组](../SPECIAL_TILES.md#匹配识别与归组已确定)；“主动组含两个落点”的情况经证明不会发生）**：横／竖连续同色的每条匹配线先独立识别；只有两条匹配线共享方块时才归成一组。相邻但不相交的两列各产一枚炸弹。每组仍按五连 ＞ T/L ＞ 四连优先级决定产物。若一个主动匹配组同时包含两个交换落点，取玩家先选中方块的落点作为产弹位置。
2. **同批嵌片触发提案**：先标记本次爆炸触及的嵌片，再按固定顺序处理其效果。批量改造为炸弹的效果先读取这一批开始时的方块，之后统一去重清除；每个原方块只计一次。这样被原爆炸波及的覆盖格也能按“整片变弹”正常播放。
3. **长连锁提案**：同一枚炸弹只引爆一次，同一事件不能反复触发同一嵌片。自动连锁仍可继续到棋盘稳定；原型用固定种子记录异常长的结算，再定保护上限与动画加速，不提前削弱正常爆发。

## 5. 玩家看见什么

- **战斗页**：始终可见剩余行动力、敌人当前意图、毒气进度、催化剂储能、已安装嵌片、神器和重力方向。选中炸弹后显式提供“点燃”操作；交换与点燃都不显示结果预览或推荐走法。
- **结算反馈**：第一次下落前显示按攻击／护盾／毒气／催化剂分列的主动基数；第一次下落之后显示被动清除数和倍率。爆炸与嵌片追加效果标出来源，玩家能回看为什么打出了这一结果。
- **嵌片页面**：三选一同时展示规则、形状、稀有度、与当前构筑的关系及是否可放入当前棋盘。战后嵌入、旋转和扩张都给合法位置反馈；已安装嵌片持续显示固定状态与仅能在商店或事件取出的说明。

## 6. 建议的下一次实际工作

先做前三战的无美术原型：四类普通方块、四种无属性炸弹、土质火药／火药嵌片／齐射嵌片、少量神器和第 3 战精英。用它验证“产弹 → 玩家点燃 → 主动基数 → 下落倍率 → 再产弹”是否真的让玩家想继续玩。再筛掉表现相近的嵌片、补满正式神器池与九战内容；数值最后测试。
