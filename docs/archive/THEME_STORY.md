# 地下秘境寻宝主题与故事提案（美术基调已选）

## 一句话方向

**暂名《地底秘藏》**：首位可玩角色是带着药剂、催化装置和火药的**炼成师**，以探险者身份深入地下秘境寻找古代遗物。洞穴、失落建筑和奇异生物逐层出现；最后击败守护悬浮遗物的巨像，带着宝藏返回地面。本局仍是固定九场战斗，最终 Boss 胜利后直接结束。

基调是**明快的地下探险**：未知空间提供探索感，炼成药剂、机关爆炸和宝物发现提供兴奋感。主角是为寻宝而来的探险者，不从事采矿。叙事由环境、敌人和少量前人留下的手记带出；首版不增加氧气、灯油或背包负重等新资源。

## 规则如何长在世界里

| 游戏规则 | 世界内解释与暂拟画面称呼 |
| --- | --- |
| 8×8 棋盘 | 炼成师携带的**炼成盘**映出面前的遗迹机关与元素流向；交换格子是在重排反应线路。 |
| 攻击／护盾／毒气／催化剂 | 规则说明保留清楚的机制名；画面可分别用**炼成刃／护符／毒雾瓶／反应晶**。催化剂为下一次主动结算蓄力。 |
| 无属性炸弹 | 封装的**炼金炸弹**，不带四种普通方块属性；玩家花一次行动力点燃，或由其他爆炸接力引爆。横、竖、3×3、五连有不同壳纹。 |
| 嵌片 | 战后取得的**遗迹嵌片**，装入随身炼成盘。四格嵌片可旋转，装好后固定；升级是在边缘添一格同材质反应区。取出仍需商店设备或特殊事件。 |
| 神器 | 在地下秘境中找到的**奇物**，获得后自动生效；少数危险奇物有公开代价。游戏规则名仍叫“神器”。 |
| 毒气进度与衰减 | 炼成毒雾在敌人周围积聚，浓到阈值使其错过当前行动；敌人回合结束时毒雾自然散去一部分。密封毒瓶能留住眩晕后的部分进度。 |
| 金币与商店 | 战斗固定获得金币；第 3、6 战后的地下营地有商人，可购买奇物、处理固定的嵌片。 |
| Boss 重力反转 | 遗迹深处的**悬浮遗物**短暂颠倒重力，棋盘中的方块向上移动并从下边缘补入。意图提前预告，毒气眩晕可打断启动。 |

画面名用于气氛，结算面板仍显示“攻击、护盾、毒气、催化剂”和“主动基数 × 被动倍率”，避免让故事词妨碍理解。

## 九场战斗的地下路线

2026-09-29：一局分三层——晶洞、封印遗迹、悬浮遗物殿，每层一个敌人家族，见 [ASSET_BATCH3](ASSET_BATCH3.md)。

| 战斗 | 场景与暂拟敌人 | 行为与推进 |
| --- | --- | --- |
| 1 地下入口 | 晶背鼹鼠 | 直接攻击，让玩家认识行动力、护盾和棋盘。 |
| 2 回声洞穴 | 洞蝠群 | 蓄力后俯冲，让玩家试着用毒气眩晕打断。 |
| 3 断层石厅，精英 | 吞光岩蟹 | 壳层吞掉一档连锁倍率；打败后发现通往深层的旧地图，进入事件与营地。 |
| 4 古门通道 | 苔甲守卫 | 防御后重击，并把方块石化；考验攻击对敌人护盾的处理。 |
| 5 孢子裂缝 | 毒孢菇群 | 攻击与防御交替，鼓励安排催化剂充能和炸弹点火。 |
| 6 封印机关室，精英 | 符链石蛛 | 用符文蛛丝预告封住玩家等级最高的一种颜色（色封），使其等级暂时失效；战后进入第二个事件与营地。 |
| 7 深层晶洞 | 拟宝匣兽 | 伪装成遗落宝匣引诱探险者，轮流使用侵蚀、石化与蓄力攻击，不再引入新规则。 |
| 8 遗物回廊 | 夺宝客 | 同样在争夺深处的宝藏，明确蓄力倒计时，为终战制造压力。 |
| 9 悬浮遗物室，Boss | 遗物巨像 | 轮流使用已学的倍率侵蚀、色封、石化和预告的向上重力异常；胜利后取得遗物并返回地面。 |

第 3、6 战后的事件可各提供一条前人留下的手记：第一次标出更深处的遗物位置，第二次提醒悬浮遗物会让空间倒悬。事件仍使用已有的金币、神器或取出嵌片选项，不新增路线分叉。营地是可休息和交易的安全点，休息区的具体互动另行设计。

## 美术方向

当前以[战斗基调样张](../assets/reference/battle-tone-concept.png)探索**手绘地下探险**：清楚的卡通轮廓、深色棋盘与明亮图标、地下洞窟与古代机关、便携炼成器具和旅装。炼成师在战斗场景中显示全身，背药剂匣，携带护符与短杖或炼成刃；顶部另有头像对应生命与护盾。第一战敌人为晶背鼹鼠，后续敌人从洞穴生物、遗迹守卫、机关和夺宝客四类取形。

棋盘方块用大图标而非写实石头纹理，先保证 8×8 棋盘在桌面网页的实际格位尺寸下认得清。爆炸可表现为炼成火花、符文与碎石飞散，整体刺激但不阴森。四种普通方块除了颜色还有不同外形；四种无属性炸弹分别用横线、竖线、方形冲击和环形清盘纹。主动清除与被动连锁使用不同的动效节奏，并始终显示文字结算。

悬浮遗物发动时，可以让背景中的火花和碎石向上飘、重力箭头翻转；棋盘方位和玩家手势不反转，避免操作混乱。

## 尚待选择

1. “炼成盘／遗迹嵌片／奇物”是否用作画面中的世界名；主角的服装、年龄与性格尚未定稿。
2. 当前基调样张中未出现炸弹与嵌片覆盖效果；这些资产在实际格位尺寸下仍须验证清晰度。
3. 营地与休息区除“升级或休息”外，要不要增加很轻的角色互动；首版可以保持纯功能。
